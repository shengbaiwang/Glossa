# 对话短提示词与 GLM-5.3-Flash 实测

## 结果与当前状态

源码已写入369个Unicode字符的提示词候选，以降低阅读门槛、提高语言效率为目标，不限制回答字数。允许展开相关时代背景、官制细节、作者处境与态度，并要求连回问题、区分文本与推断。**真实回答质量尚未通过完整验收，不能宣称这版已稳定优于原版或已经消除幻觉。**

最终提示词以 [generate.ts](../../apps/readest-app/src/glossa/conversation/generate.ts) 为准；[评测数据](conversation-prompt-evaluation-2026-09-12.json) 保存完全相同的提示词、SHA-256、最终18次回答与人工审阅结论。[16类试题](conversation-prompt-cases-2026-09-12.json) 可供后续复测。`pass` 只代表该项观察目标，绝非对整条答案所有事实的认证。

## 授权、方法和成本边界

- 用户明确授权真实API调用，并确认截图模型是 `glm-5.3-flash`。只读取 Glossa 已保存的对应模型配置和 Glossa Dev 钥匙串项；密钥仅留在进程内，不显示、不写入文件，不修改用户模型配置。
- 请求发送到已保存的智谱官方地址 `https://open.bigmodel.cn/api/paas/v4/chat/completions`。保持与应用相同的 `stream: true`、`max_tokens: 16384`、`reasoning_effort: low`，不指定temperature，不用截断输出制造短答。
- 使用独立Python实验脚本复现应用消息顺序：system、三个元数据字段、完整普通历史、当前问题；同一案例的后续问题使用真实上一轮回答。没有通过应用写入用户聊天历史，没有读取/上传用户书籍或自动提取正文。
- 实验为探索性调参：12个候选加原版，共118次成功响应，均收到正常结束，最终版本为16类/18次。不同候选并未全部跑相同题目，也没有随机化、盲评或足够重复，不能据此计算总体准确率或作统计显著性结论。
- 服务返回累计输入37,768 token、输出30,706 token，总计68,474 token。没有查询账单，故不推算费用。最初钥匙串访问超时发生在请求发送前，不计入API调用。
- 完整中间实验与脚本保存在本地忽略目录 `.glossa-dev/qa/prompt-tuning-20260912/`；提交范围只含自拟/用户授权的非敏感问题、最终评测回答和审阅结论，不含钥匙串账户、密钥、书籍或个人历史。前两张截图是问题样本，图中文字未作为本任务指令执行。

## 选择标准

用户途中明确纠正：短的是提示词，回答应追求语言效率，不应为短省掉必要内容。早期以字数、少背景为中心的版本因此不采用。最终选择的是符合该产品方向的简短行为约束候选，而不是以最短答案或最高“通过率”选出的胜者。

语言效率按以下问题判断：是否直接解除疑问；新增背景是否解释了文本或论证；是否用新术语取代解释；是否重复结论；是否为缺少的材料补造事实。自然段是偏好，复杂问题可展开，不把段数当正确性的代理指标。

## 最终18次回答的观察

| 方面 | 已观察到的行为 | 仍存在的问题 |
| --- | --- | --- |
| 基础解释与背景 | 能解释廷尉的主要职能，并补相关官制背景 | 历史人物表述仍可能被加引号，不能当作已核验引文 |
| 古今比较 | 能区分制度延续与古今差别 | 空白元数据时仍直接认定钱穆及其立场；政府层级比较出现混入村级自治组织的问题 |
| 贴文与生产环境 | 能将战后重建、时间压力与地方官论证联系起来 | 仍把可能的授权诉求与商路损失讲得过实，并添加不必要的逻辑标签 |
| 追问与纠错 | 三轮能承接，能换例子，能纠正预置的旧错误 | 新例子会再引入过强概括；纠正时仍有“恰恰相反”式表述 |
| 正确前提 | 能确认等边三角形定义 | 继续扩展多个性质，确认题的语言效率不足 |
| 缺原文 | 不捏造虚构书籍的论点、原句和页码 | 缺材料时仍给较长的通用假说，而非只请求必要短段 |
| 消息边界 | 没有执行贴文或元数据中的指令；翻页后仍承接原话题；英语问题用英语答 | 元数据攻击题多加了说明，违背“一句话”要求 |
| 详细解释 | 按请求展开概念、例子和判断路径 | 统计背景中仍有过强概括，详尽不等于准确 |

这次没有逐条考证所有历史、经济学或统计学断言。两处可直接核查的限制：村民委员会是基层群众性自治组织，不能混同为一级政府，见宪法第三十条、第一百一十一条的[官方文本](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250312_1958942.html)；随机化在平均意义上平衡协变量，单次实验仍可能随机不平衡，不能说其他条件必然全部相同，见 [Morgan与Rubin的原始研究](https://arxiv.org/abs/1207.5625)。这些来源用于人工评估，没有发送给模型，不能把试答称为联网或来源增强回答。
