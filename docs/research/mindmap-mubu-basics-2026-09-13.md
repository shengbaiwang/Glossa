# 幕布式阅读导图：基础功能建议

日期：2026-09-13。用户倾向幕布式简洁高效，并要求直观可靠地呈现文章观点层级。本轮为方案讨论，未授权整套功能实现；不修改现行 PLAN、产品代码或简单对话边界。

## 核心方向

建议采用“一份有原文依据的观点结构，大纲与导图两种视图”。大纲用于快速阅读、检查和轻量修改，导图用于查看主次、展开论据、核对来源。视图切换只改变展示，不再次调用模型；节点身份、文字、父子关系、排序、来源和已展开分支一致，切换保留当前节点。

幕布官方明确支持大纲与导图切换，以及 Enter 新建主题、Tab/Shift+Tab 调整层级、拖动排序、小三角折叠等操作。[视图切换](https://mubu.com/help/11)、[快速编辑](https://mubu.com/help/10)、[快捷键](https://mubu.com/help/14)、[折叠](https://mubu.com/help/7)。这些说明是功能参照，不构成幕布 AI 忠实度实测。

## 基础能力

| 能力 | 建议规格 |
| --- | --- |
| 选段生成 | 沿用明确 EPUB 阅读段，生成可取消、失败可重试；简短显示当前篇章/段名，生成后收起配置。 |
| 大纲 / 导图 | 同一结构即时切换，切换不重新生成，不丢内容和选择位置。首次可显示导图，随后记住选择。 |
| 层级浏览 | 单支展开/折叠、按层展开、全部收起、聚焦某分支和返回全图；记住折叠、字号及位置。支持键盘与节点搜索，搜索命中展开祖先。 |
| 直观视图 | 默认一种有序树布局，主观点突出，子观点/论据/例子渐次展开；短句、细连线、纸墨主题。支持平移、缩放、恢复可读比例、临时放大；窄栏以折叠和分支聚焦保证可读性，不把整图缩成小字。 |
| 原文核对 | 浏览模式单击文字直达本地核验的主要来源，三角只折叠。可返回阅读原位；次要操作顺序查看其他依据，图面无编号、角标或解释卡片。定位失败不猜跳。 |
| 轻量修改 | 通过明确的编辑入口修改短句、关系和层级，新增/删除/移动节点，撤销/重做；快捷键仅在编辑区域生效。改写与重挂父节点都可能改变事实含义，不能继承原来的已核验身份。保留生成原版，用户内容明确为个人整理。 |
| 保存与恢复 | 自动本机保存、保存失败提示和重试、重生成保留旧版、恢复上一版、可查找已有图。结构化备份/恢复属于耐久性后续项；图片/Markdown 导出属于成果复用后续项。 |

## 层级表达规则

1. 根节点为当前材料的核心问题、中心判断或主题；只对已选材料负责，不推断全篇或全书结论。
2. 主分支是实际主要观点，避免机械复制文章目录；同级节点保持相近概括粒度。
3. 子节点表明理由、证据、例子、条件或异议与父观点的关系；不能把不同作用都处理成同一种“子话题”。
4. 标签优先“主体＋判断”的简短命题，例如“例子的解释范围受条件限制”，而不只写“例子”“条件”。以一至两行可读为目标，不因硬性字数删掉否定、条件或主体。
5. 基础分组关系由缩进与连线表达；支持、反驳、限制、对比等必要语义用简短关系词显示，方向必须一致。可用父到子读法“依据是”“受限于”“例子是”，避免把层级方向误当成因果方向。
6. 因果词只在原文有依据时使用；叙事/说明文按其实际结构组织，不强制套入论证模板。无足够依据时允许减少节点、保留主题并列，或返回证据不足。
7. 同一概念与多个分支有关时，先保证主树清楚；若确有需要，再增加默认隐藏、聚焦时展示的少量跨分支关系。

原创示意（用于解释组织规则，不是从用户书籍提取）：

```text
例子的解释力有边界
├─ 理由：例子能使抽象观点具体化
│  └─ 例子：一个案例呈现机制如何发生
├─ 限制：单个案例不能代表所有情形
│  └─ 条件：结论只适用于相似背景
└─ 建议：引用案例时同时交代适用条件
```

“可靠”分为结构一致、来源可抵达、语义被原文支持三个层次。前两项适合确定性校验；第三项需真实材料逐关系评测与方便的人工核对。不能把锚点有效或模型自行标为 source 当成语义证明。原文陈述和理解性解释需能在键盘/触控可访问的节点信息中区分，不能只依赖颜色或悬停；直接推断节点可使用“可理解为”等自然限定，避免以作者口吻陈述推断。

## 简洁界面与分批取舍

常驻顶部建议只保留篇章/段名、大纲/导图切换、放大和更多菜单。生成入口仅空状态突出，重新生成、层级显示、字号、编辑、历史等收纳进更多菜单；节点附近只出现当前相关操作，保持正文并排。

第一批建议交付双视图、层级折叠/聚焦、可靠跳转与返回、保存恢复，并建立观点结构质量样本。第二批补轻量编辑和键盘效率、节点/历史查找。若编辑进入同一交付批次，撤销、原版保留和来源身份处理必须一起完成。模板市场、自由配色、任务/演示、多人协作和多种图表不列为当前基本要求。

当前实现已有选段、生成、折叠、字号、来源直达/返回及本机保存；双视图、编辑、分支聚焦与版本恢复是新增建议。基础流程仍限定已选择 EPUB 段，不恢复整书发送、全文检索或对话正文上下文。

验证：公开文档及当前设计/`MindmapDocument.tsx` 静态检查；未实操幕布、调用模型或读取书籍。仅文档变更，无需产品测试。
