# 网页导入重构验证

日期：2026-10-29。源码实现遵循 [重构方案](../design/web-import-rebuild-proposal.md)。未改写个人书库、未替换 `/Applications/Glossa.app`，没有提交或推送。

## 已交付的路径

- URL → 有界 HTTP（HTML 16 MiB／PDF 64 MiB、12 秒）→ 本地正文提取；真实 PDF 进入既有文件导入。
- HTTP 无可用正文 → 隔离 WebView → 自适应稳定性判断 → 直接脚本回调返回 HTML、重定向后 URL 与 base URI；不再将 HTML 塞入导航 URL。需要登录／展开／选文时，在原弹窗继续打开捕获窗口。
- 固定 Defuddle 0.19.6，同步提取、禁用异步服务；主提取不合格才尝试 Readability，有可信语义正文时逐块核对章节、代码、列表、旁注及参考条目，缺失则保留同根原结构；科学富结构优先语义路径。独立读取元数据，显式登录／验证／不可用页面被拒绝，短文及图片为主文章不受旧 400 字符门槛限制。
- 网页打包为 EPUB 3，保留安全 MathML／SVG、代码、表格、图注、脚注目标及互链；来源、范围、提取版本、捕获方式和缺图列表写入包内 `source.json`。完全相同内容和资源保持确定输出，URL 本身不作个人记录合并依据。
- 资源下载受单图、总输出、并发窗口和总时间约束；缺图保留原位后备和远程来源链接，显示数量，可主动重试。新输出沿用完整身份入库，不覆盖已导入版本上的笔记、进度或改名。
- 学术摘要存在出版者声明的 PDF 链接时，明确选择导入摘要或全文 PDF；不自动遍历论文链接。保存失败可复用本次已完成的转换，取消／关闭／设置变化使重试缓存失效。
- PDF 以实际文件签名决定预算，缺少 MIME 或使用 octet-stream 的 PDF 也可使用 64 MiB 上限；网页仍限 16 MiB。原网页、最终下载地址与摘要页来源随新书记录持久保存，不修改 PDF 字节；重复导入保持原记录和个人数据。
- 系统分享在实际入库阶段仍传递取消信号，分组只随新增记录原子保存；重复分享不会在入库后改写个人分组，视图发布不另做一次旧快照保存。
- 扩展提供无需登录的本地 EPUB 下载；云端发送为独立主动动作。浏览器 Cookie 留在浏览器，不转移到应用。

## 验证方法与证据

1. 新增原创回归先复现旧问题，再修复：短文误拒、登录墙误入库、空提取备用、元数据、来源、摘要、图片文章、XML／公式／表格／脚注、资源超限与停滞、取消、保存重试和插件停用。
2. 使用真实 Chromium 检查浅色／深色、390px／900px、RTL／电子墨水下的进度、原位恢复、缺图结果和摘要选择；截图位于忽略目录 `.glossa-dev/qa/web-import-20261029/`。
3. 用实际网页转换产物打开 Foliate EPUB 阅读器，检查离线正文首尾、图片解码、MathML、表格、脚注目标和不执行来源脚本。该检查发现 `aside` 脚注目标丢失，已加入回归并修复；不能只以生成 ZIP 或包含链接作为脚注完整证据。
4. 隔离 macOS Tauri／WKWebView 原型使用原创本机 HTTP 夹具，独立 identifier、临时目录与非持久捕获窗口。检查 2 MiB HTML、302 跳转、延迟正文、富文本选文、任务所有者、预注册取消、命令／工具栏取消和无残留窗口。可复现示例在 `apps/readest-app/src-tauri/examples/`，脚本契约用例在 `apps/readest-app/scripts/test-native-clip.mjs`。
5. 40 个公开 URL 的 HTTP 快照及算法诊断位于同一忽略目录，涵盖中文／英文博客、资讯、学术正文、摘要、登录／动态页；与原创回归集合分开统计。检查没有使用用户的账号、Cookie 或私人正文。
6. 对其中 21 篇普通文章／博客及 3 篇学术全文逐篇对照，首轮发现 5 篇关键内容丢失：作者附录列表、教程代码章节、正文侧栏和参考文献。已以原创等价回归修复并重新核对这 5 篇；当前记录 23 篇已取得主要正文可直接阅读，1 篇 HTTP 快照仅含动态绘图占位，完整呈现无法判断。口径为 24 篇初审加 5 篇修后复核，其余 19 篇没有在修后全部重新导出；不作为冻结版 24 篇成功率或总体网页成功率。原始与修后理由见忽略 QA 目录的 `quality-review.json`。

最终命令、计数和检查结论见 [PROGRESS.md](../../PROGRESS.md) 中同日网页导入记录。运行日志保存于本机 QA 目录，源码库不收录公开页面全文。

## 结论的范围

- 公开样本的 HTTP 状态和提取候选只用于发现缺陷；未完成每篇人工正文完整性复核，不能据此宣称已达到普通网页 90% 成功率，也不代表用户常用站点。
- 原生原型验证捕获桥和生命周期；Chromium 验证实际 EPUB 阅读。它们不能代替日常安装版中从导入到离线阅读的完整设备验收。
- 移动端补齐最终 URL／base URI 和真实取消转发；iOS 控制器通过模拟器 SDK 类型检查，全插件 Swift 通过语法检查。两平台完整构建与真机、外部登录服务和系统分享分别待验收。
- 扩展完成逻辑回归和生产打包，浏览器安装、下载授权及系统文件接收尚未实际验收。纯 Web 继续受跨站访问限制。
- 提取、DOM 清洗及网页资源封装仍运行于主线程；有界输入和主算法短路降低工作量，但尚无真实长文峰值内存、端到端 p50／p95 或持续交互基准，不声称硬内存上限或固定加速倍数。
