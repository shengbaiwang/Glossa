# 轻量阅读 harness

日期：2026-09-21。用户在[案例调研](../research/reading-harness-assessment-2026-09-21.md)后授权实施。目标是完成「附加原文 → 提问 → 必要时补读 → 回到原文」，复用现有阅读器与对话。

## 阅读者看到的行为

对话输入框的「引用原文」提供当前页、所选文字，以及章节内阅读段选择。未附加时保持基础 API 对话。附加只读取本机内容，按下发送才调用模型；当前页按实际可见范围裁剪，选区保留精确边界。主动选择的阅读段可以位于书内其他位置，不把当前位置误当成已读历史。

附加内容按会话固定并可展开查看，随后翻页不改变它。新会话从无原文开始；移除或换用其他原文后，旧范围回答仍可阅读，但不会越过新范围进入请求。关闭重开保留该会话附件。每次重新生成分别保存所用范围、证据与回答版本。

回答保持 Markdown。合法引用可点击，复用来源面板从本机书籍恢复原文并核验，再跳到出处；可返回跳转前的阅读位置。无效来源不能成为可点击引用。普通解释、背景知识与原文观点要求模型在行文中区分，不强制一套长回答模板。本机仅能验证文字及定位，不能自动证明模型的解读。

## 最小执行层

`glossa/harness/scope.ts` 定义格式无关的 `ReadingScope` 与只读操作；`epub.ts` 封装 Readest/Foliate 的可见范围、原生选区、章节阅读段与 CFI，不让引擎对象进入 AI 核心。`generate.ts` 通过 provider 完成有界工具循环，UI 不直接调用厂商 SDK。

| 工具 | 行为与边界 |
| --- | --- |
| `get_outline` | 返回所附范围内的标题与来源 ID；目录列出 ID 不代表模型已读到正文。 |
| `search_book` | 对所附范围做本地词语/短语匹配，最多五条完整来源；不调用现有全书搜索，不扩展权限。 |
| `read_passage` | 根据已存在的 ID 读取最多五处完整来源；越界 ID 返回错误。 |

模型接收 `sourceId` 与文字，不接收可信页码/CFI，也不能创建或修改锚点。工具参数、服务响应、本机历史和来源关联均运行时校验。正文与工具结果属于不可信阅读数据；其中的指令不得提升权限。

先确定性提供证据：当前页/选区全部发送，过长则要求缩短；阅读段先按问题匹配，未命中则从开头选择完整块，通常最多 4,000 字符。模型只有需要时再调用工具。工具执行最多三次、provider 请求最多四次，合计 90 秒；去重原文累计不超过 12,000 字符，整段不裁成假完整来源。本机阅读段快照沿用 20,000 字符/200 来源上限。

阅读追问仅使用同书同范围的完整轮次，最多八轮/12,000 字符。历史来源先与当前快照完整核对，再重供实际引用的原文；无引用回答用其原有证据作为有界后备。证据放不下的整轮不发送。移除原文后，普通对话组装器排除阅读回答。基础聊天自身的十二轮/48,000 字符上限保持不变。

provider 支持标准 Chat Completions function tools 流式参数与结果。只有明确表示不支持 tools 的 400/422 服务响应才退回所附证据直接回答；认证、限流、网络与未知错误直接报告。退回时不声称已搜索，界面显示「依据所附原文」。厂商专有 reasoning 字段回传、Responses API 等不在首版实现内，真实兼容服务仍需逐一验证。

## 持久化与验证

沿用 `glossa-conversations` 与 `conversation-3`，会话可选 `readingScope`，每个回答版本可选 `reading: {scope, sources, mode}`。旧记录缺省这些字段，继续可读；跨书记录、来源被修改或脱离该快照的记录拒绝加载。模型服务身份与密钥继续分离，不新增正文日志、遥测或同步。

单元验证覆盖范围校验、裁剪、工具参数/次数/预算、追问证据重供、流式取消/超时、不支持工具退回、来源白名单与历史版本。浏览器用原创合成 EPUB 与真实 Foliate 验证附件、翻页、工具、核验跳转、返回原位及本机恢复；模型响应采用模拟服务。主题检查包括 420px 浅色、320px 深色、RTL 与电子墨水。

后续验证以日常阅读中的真实问题为准：记录回答能否解决疑问、引用是否支持解读、补读是否有用、等待是否打断阅读。未证明需要前，不增加 embedding、全书工具、网络搜索、多 Agent、持久研究任务或自动写笔记。
