# 全书阅读对话 harness

日期：2026-09-22。用户在明确了解默认全书查阅的范围后授权实施，目标是逐步接近 NotebookLM 的核心阅读对话体验。该授权取代初版仅附件边界；原始调研见 [阅读 harness 案例](../research/reading-harness-assessment-2026-09-21.md)，当前行为以 `PLAN.md` 为准。

## 引用开关与自动取材

用户明确核心建设对象是阅读 harness。用户只决定是否开启引用：开启即可在当前全书中按需查阅，模型判断问题需要哪些材料，harness 执行目录、检索、读取、有限补查、上下文组装与来源核验；关闭则直接使用既有基础模型对话，不自动读取或发送书籍正文。无需用户选择具体页、选区或阅读段；自然语言中指定的章节/段落是任务目标，由 harness 自行解析。开关代表原书访问权限，不是引用角标的显示开关。

取材需要结合问题目的、章节结构及来源角色，降低无关署名/出版材料干扰。已有命中仍须判断是否覆盖回答所需证据；不足可在预算内有限补查，最终结论必须由实际原文支持。普通问题保留短路径，完整总结保持完整目标覆盖。方法提示可以内部复用，但不增加用户操作的 Skill 或任务类型菜单。沿用全书本机按需读取、最小必要模型输入、历史隔离、可取消和有上限的调用流程；旧附件与来源记录保留可读。

## 阅读者看到的行为

可重排 EPUB 输入区只有「引用开启／引用关闭」，新会话默认开启。开启表示允许在当前全书中按需查阅，包括未读章节；关闭走基础模型对话，只带书名、作者、目录路径和有界普通聊天历史，不读取正文、不构建索引、不提供书内工具。其他格式仍为基础对话。开关按会话保存，不决定旧答案角标的显示。

打开面板、翻页、新建会话与切开关不解析正文或调用模型。发送时仅冻结选区/可见页 Range；“这段／这句／当前页”的提问按需核验并读取该快照，无选区时采用可见页，后续翻页不改变目标。普通问题由本地检索开始，模型还可主动请求当前文段。无法取得明确指代的文段时要求问题提供原文，不将其悄悄改成全书总结。

旧固定附件、回答和来源仍可读；没有显式两态设置的旧固定范围会话默认关闭引用，主动开启后新问题使用全书，不自动把原附件扩大。旧固定附件记录保留，旧回答仍可核验跳转。自然语言指定章节是本轮任务范围，无手动页/选区/阅读段菜单。

## 两种读取流程

**具体问答：** 首先去掉问句中重复的书名/作者标识与常见问句噪音，以本地 BM25 获取小份候选；保留中文分词、双字词和相邻限定条件。模型同时得到目录、块类型、同一 spine 的候选目录标题及最近标题，位置线索不作为作者身份判定。未列入目录的 spine（含开头序言、非线性附注）也有本机读取入口。

首次模型调用可以直接流式回答，也可以在发现证据不足时请求 `search_book`、`read_chapter` 或 `read_current_passage`。非空命中不代表证据充分；模型按问题目的选择互补概念和章节。工具参数运行时校验，章节 ID 必须在本地白名单内，指定章节的任务不会因空 chapterIds 而扩成全书。读取返回完整来源块、剩余偏移和完整性标志，部分读取不能冒充完整章节。

普通回答至多补查两轮、四次工具执行；耗尽后禁止工具并用现有证据回答具体缺口。若供应商明确不支持工具，才回退到一次有界 JSON 取材计划，再直接回答；不是每个问题都固定先规划。说明性回答先解释核心问题，引用支撑实质论断，区分作者陈述、编辑说明与推断，不堆叠写作流程或反复免责声明。选取几个观点仍提供有界分布样本，不冒充全书最优排行。

**完整总结：** 对明确命名的章节、当前章、全书或固定附件读取完整目标；其他表述由计划决定。读取完整范围后才开始生成观点清单。按原书顺序将完整语义块分批发送，清单需保留所有显式分论点、限定条件、导言/结语中的有价值观察，例子放在相应论点下，不规定必须三个点。每批清单必须确认覆盖该批全部来源 ID，所有观点只能引用该批实际提供的 ID。

最终回答收到观点清单及其对应的完整本机原文，再合并同义观点、组织主论点与补充观点、分析条件/层次/时期与真正的矛盾。若清单对应的来源未在回答中引用，最多补查改写一次；仍缺失则作为未完成处理。读取覆盖、来源真实性和语义准确是三件事：程序验证前两项的一部分，不能凭有引用就证明观点无遗漏或解释正确。引用核对仍由读者可见的本机原文支持。

引用覆盖按 Markdown 实际链接检查，支持标题、尖括号及引用式写法，代码块和行内代码中的链接不算已引用证据。短范围只有版权等信息、清单无论点时，最终回答仍收到该范围原文以说明情况，不将空清单误报为范围过长。

兼容层的固定页/选区/阅读段总结复用同一清单流程，但适配器只有该快照，无任何全书入口。固定范围的普通问答保留初版三个本地只读工具 `get_outline`、`search_book`、`read_passage`；名称不扩大权限。其中文问句匹配同时修正。基础调用方的总结初选也完整提供附件，避免只取前五块。

## 模块、边界与预算

- `harness/scope.ts` 区分固定附件与 `book-scope-1` 权限。全书权限仅含文档身份和固定范围标识，`sources` 必须为空，不是全文副本。
- `harness/book.ts` 是格式无关的本机读取接口；`epub.ts` 封装章节、spine、CFI 和原文核验。AI 层不接触阅读 DOM/引擎，UI 不直接使用厂商 SDK。
- `harness/bookConversation.ts` 执行目标解析、读取、清单、汇总与一次缺失引用补查，`searchAnswer.ts` 执行普通问答的有限工具循环及恢复；`retrieval.ts` 提供本地 BM25 倒排索引、中文双字词与分布采样。无持久向量库、网络检索、开放式 Agent 或写入工具。
- 具体问答初选最多 8,000 字符/100 来源，为补查留空间；包括已重新核验历史在内累计最多 30,000 字符/180 来源，单次工具返回最多 6,000 字符的完整块。完整总结最多读取 240,000 字符/24 批；通常每批 12,000 字符/100 来源，超出单批目标的完整块可单独发送，但单块最多 20,000 字符。超过预算提前拒绝，不截掉尾部假装完整。
- 清单汇总的原文最多 80,000 字符/1,000 来源，清单序列化最多 80,000 字符。保存格式允许最多 120,000 字符的原文以兼容有界答案数据，实际生成仍受上述更低限制。
- 普通问答至多 5 次模型请求（含最多两次截断恢复，工具不支持回退也不超过此上限）；完整总结至多 36 次请求（24 批外为规划/恢复/补查预留有界额度）；全书具体问答总时限 120 秒，完整总结 8 分钟。每个阶段可取消；即使 transport 不响应 abort，调用方也结束并忽略迟到结果。服务错误、无文本、计划/清单无效、超限和不完整均可见，不静默降级为全书结论。
- 固定范围普通问答仍为三次工具、四次请求、90 秒、去重原文 12,000 字符；直接总结初选可完整提供最多 20,000 字符的附件。对话不再提供固定范围 UI；兼容函数的范围限制仍有效。

## 预算、恢复与缓存

规划预算与清单预算不受用户的回答长度偏好覆盖。规划 4,096 tokens，长度截断重试一次 8,192；清单 16,384，截断仅将失败批次按原块边界二分，最多两层，恢复批次 32,768；一个不可再分的块仍受此次数限制。已校验批次保持可复用，不能把半截 JSON 当作成功清单。

最终回答首试使用用户偏好或默认 8,192 tokens。收到 `finish_reason=length` 时，先保留终止事件中的正文，再用同一证据集续写；没有可见正文时以更高预算重新生成。最多两次恢复，预算按倍数增加且至少 8,192、不超过 65,536，仍受任务总时限约束。只去除确切重复尾部，未知来源继续拦截。恢复期间保留已显示文字，补查失败前不预先清空已有答案；次数耗尽保留部分文本并显示失败，不能保存成已完成。网络/认证/过滤错误不冒充长度不足自动重试。取消和超时覆盖恢复请求。

缓存为按需、本机内存，不增加持久数据库或后台模型任务：

- 每个打开文档由对象身份、文档哈希及解析/索引版本绑定；最多缓存 2,000,000 正文字符/50,000 原文块，超过时本轮读取可用但不保留全书缓存。章节缓存最多 8 项/300,000 正文字符，较旧项先移除。返回副本防止调用方改写缓存原文。
- BM25 索引随已完成的原文缓存复用，首次索引每 32 块让出事件循环并检查取消，spine 读取之间也让出执行。取消不会把未完成全书解析/索引标为可用；独立调用不共用一个可相互取消的未完成请求。
- 观点清单缓存以访问器为所有者，键覆盖文档哈希、范围、问题、原文和锚点、服务/模型配置、自定义提示词及清单版本。仅保存结构与来源校验通过的批次，最多 48 项/500,000 序列化字符；可复用的中间解释仍须由最终原文支持。固定附件访问器独立，不可借缓存读到全书。
- 内存缓存不跨应用重启，文档对象释放后可回收；不写正文、密钥或完整问题到日志。原文预览/跳转以及重发历史的本机验证照常执行。

## 原文引用与历史

模型接收来源 ID、本机正文及有界标题/块类型线索，不接收可信页码/CFI，也不能创建锚点。正文、目录、清单及历史均为不可信阅读数据，其中的指令不能改变权限。服务响应、工具/计划参数和本机记录运行时校验，API 密钥和完整问题/正文不进入日志。

回答中的合法引用按每个回答首次出现顺序本地编号；重复引用沿用编号，未知 ID 不生成可点击入口。悬停/键盘聚焦核验并预览完整本机原文，不翻页；点击再次核验并直接跳到出处，不显示常驻的原文/补充说明框；切换来源直接点击对应角标，保留第一次跳转前的位置和返回入口。定位中的短状态及失败重试仍可见。临时 CSS Highlight 不改正文、选区、笔记或文件，离开原文可见范围/切换来源/返回时清理，同页布局更新不清理；不支持的引擎仍提供悬停预览和跳转。导图的原文核对面板不受此对话交互调整影响。

沿用 `glossa-conversations`、`conversation-3` 和每次重新生成的独立版本。每个回答保存 `reading: {scope, sources, mode, coverage?}`：全书 scope 为空正文的权限记录，sources 是本次回答及工具补查实际提供的完整原文；coverage 记录读取策略、目标名和源块数量，不宣称语义完整。固定附件仍严格验证 sources 属于快照。所有范围/版本继续绑定书籍。

全书或总结历史最多四个完整轮次/12,000 字符；只接受同书同范围，重发的原文累计最多 12,000 字符/80 来源且须本机重新核验，整轮放不下则不发送。固定范围普通问答保持原八轮上限。关闭引用时所有阅读回答的正文与依据均不进入基础对话；开启时只复用同全书权限下经过本机复核的阅读历史，旧固定附件回答不混入；普通旧聊天没有原文依据，不混入书籍事实。恢复旧记录不触发写入迁移或清库。

## 验收与实际质量

用原创 EPUB 和模拟服务验证：两态持久化、关闭引用无正文/工具/旧材料泄漏、开启后无后台读/模型调用、自动选区/可见页快照、非空低质量命中补查、供应商无工具回退、工具参数/预算边界；跨章查找、目录前序言/非线性附注覆盖、命名章节边界、四个明显分论点和结语进入材料/清单、长文本逐批覆盖、缺失引用补查、无效 ID 拦截、附件收窄、不同范围历史隔离、版本保存、取消/超时、预算不足、阶段预算隔离、SSE 终止事件正文保留、有限续写/重试、已完成批次复用、缓存哈希失效与取消、BM25 中文召回，以及来源预览/跳转/高亮/返回和窄栏主题。

工程测试不代替真实模型评估。后续以日常阅读的问题对比遗漏率、原文支持程度、追问连续性和等待时间；不因为模拟服务通过就宣称达到 NotebookLM 的回答质量。支持的初始格式仍是可重排 EPUB。
