# 分组交互设计

日期：2026-10-18；2026-10-30 更新。用户已要求接入正式应用并贯通拖放、快捷搬运和多步撤销／重做；本文记录当前实现与保留的验收边界。

## 界面与入口

常态只显示「分组」标题与内容树，没有底部「新建分组」、操作提示或「已新建／撤销」条，不出现悬停编辑按钮。选中行使用轻底色；有子分组的节点保留必要的展开箭头，普通叶节点不增加编辑控件。分组小图标可保留，菜单动作使用文字。

点击标题或在标题／空白处右键、长按，可以「新建分组」。在具体分组的菜单中「新建子分组」。撤销放在同一个菜单中，只有存在可撤销操作才出现，文案保持「撤销」；保留 Cmd/Ctrl+Z。新建快捷键为 Cmd/Ctrl+Shift+N，不在页面底部重复显示。

## 层级与拖动

当前实现从两层扩到**最多四层**，包含最外层。四层是当前实现的有界起点，不作为不可变的长期限制，也不加入面向用户的层级配置开关。

| 拖动位置 | 放下后的行为 | 仅拖动时显示的反馈 |
| --- | --- | --- |
| 目标行中部 | 移入目标分组，成为最后一个子分组 | 目标行轻高亮 |
| 行的上／下边缘 | 插入该行之前／之后，与目标同级 | 一条插入线 |
| 标题或列表空白 | 移回最外层，置于末尾 | 标题轻高亮与空白处插入线 |
| 已折叠分组中部停留片刻 | 自动展开，以便继续选择子层落点 | 展开后更新落点 |
| 自身或自身后代 | 不移动 | 无效落点与必要的简短提示 |
| 移动整个分支后会超过四层 | 不移动，不截断或拆散后代 | 仅在受限时提示「最多 4 层」 |
| 书架分组卡片／路径导航 | 移入对应分组；路径根节点解除归组 | 目标轻高亮 |
| 有效目标以外／Esc | 取消，恢复原结构与临时展开／进入状态 | 清除落点反馈 |

拖动整个分支，书籍与子孙分组一同保留。判断深度时计算整个分支高度，不能只检查被拖动的第一层。只在有效放下后提交变更；拖动中不写入用户库、不提前改名或改变书籍归属。跨层移动后同层重名时，为移动分组自动编号，不合并、覆盖其他分组。

普通拖动只保留紧凑的图标／名称浮层、目标高亮与插入线，不显示「移入某分组」「放在某分组之前／之后」「移到最外层」等说明，也不在列表底部加入拖动提示。移出列表取消时安静恢复，超层提示不扩写分支高度等内部校验规则。

桌面鼠标按住条目并移动越过阈值开始拖动，不另加拖动把手。触屏长按后不移动打开菜单，保持按住并移动则进入拖动；普通滑动保留滚动。长按与拖动结束不再触发一次误选或意外改名。菜单中的「移动到…」提供触屏与键盘的替代方式，在原菜单中选择目的地，不开集中编辑表单。真实设备与系统 WebView 手势仍须正式接入后单独验收。

## 展开、导航与键盘

- 有子分组才显示展开箭头。左右键折叠／展开或进入父子节点，上下键及 Home／End 移动焦点，回车激活；折叠后将不可见子节点焦点收回父节点。
- Alt+右方向键移入前一个同级分组；Alt+左方向键移到上一层、排在原父分组之后，保持有界深度校验。菜单「移动到…」是无需记忆快捷键的等效入口。
- 移动当前分组时继续停留在该分组，展开目的地祖先链，便于找到新的位置；书籍身份保留；沿用路径哈希表示分组，并映射当前页面与焦点到新路径。
- 菜单键／Shift+F10、右键与长按进入同一套操作。Esc 关闭菜单或取消拖动，结束后恢复有意义的条目焦点。

## 新建与命名

重命名保留原行的图标、展开箭头、缩进、名称起点、字号、字重及行高，也保留当前分组的选中底色。名称直接在原位编辑，不加边框、焦点描边、底色或下划线，不显示勾叉、教学文字或额外操作栏；以选中文字与光标反馈输入焦点。进入时选中全文；回车／失焦完成、Esc 恢复，保存后的下一次点击继续生效。输入法组词时 Enter／Esc 只操作候选词；组词过程中失焦，等候选结束后保存最终名称。侧栏、书架及移动面板的新建共用这一输入外观，触屏保持命中区，字号不另行放大。

| 情况 | 行为 |
| --- | --- |
| 菜单选择新建 | 对应层级出现原位名称输入，空输入提示「未命名」，完成时未输入则采用该名称，不显示勾叉 |
| 回车／点击别处／键盘移出 | 完成命名；点击其他条目的导航继续生效 |
| 新建时为空白 | 使用「未命名」；已有则依次为「未命名 2」「未命名 3」 |
| 主动输入的新名称重名 | 新建时自动加数字后缀，实际名称在行中可见 |
| Esc | 取消新建；改名时恢复旧名，焦点回到条目或标题 |
| 中文输入法组词 | 回车只确认候选词，不提交名称 |
| 双击／F2／菜单「重命名」 | 原位选中名称，与新建共用安静的输入方式 |
| 改名后为空白 | 保留旧名称 |
| 改名与同层名称冲突 | 保留输入并行内提示「已有同名分组，换个名字试试」 |
| 含路径分隔符等非法字符 | 行内提示，保留输入；沿用 120 字符上限 |

第四层不显示「新建子分组」，其余新建、拖动和菜单移动使用同一层级校验。新建后聚焦新行，父层自动展开。保存失败保留输入，避免重复创建，不在底部加常驻状态条。

## 删除与恢复

空分组直接删除，常态列表不出现撤销条。非空分组只作一次轻量确认，说明书籍与子层如何处理。例如：

> 删除“历史”分组？
>
> 3 本书会移到「全部书籍」，笔记与阅读进度保留。其中 1 个子分组会整体上移一层。
>
> 取消　删除分组

只删除选中的分组：直接所属书籍移到上一层；根分组书籍解除分组后仍在「全部书籍」。直接子分组整体上移一级，其下结构不拆散；重名自动编号。原书、笔记、书签与进度保留。

删除当前分组后回上一层或全部书籍；仍存在的子分组页面保持可用。保存成功才移除，失败保留原结构与关联。撤销从上下文菜单或 Cmd/Ctrl+Z 触发，恢复名称、层级、顺序、书籍归属和必要的导航；名称输入中保留系统文字撤销。

正式实现保留最近 30 步分组操作的撤销／重做：只恢复受影响书籍的分组字段，保留最新书名、进度与其他元数据；分组目录、受影响成员或自动导入映射发生冲突时拒绝恢复，不能用整库快照覆盖后续编辑或同步结果。保存失败不消费历史，成功的新操作清除重做分支；菜单／键盘错误反馈与屏幕阅读器播报保留，成功反馈由内容变化本身表达。

## 快捷搬运（2026-10-30）

- 网格、列表与侧栏使用同一目标校验。书架可混选书籍与分组，侧栏拖动完整分支；落点包括侧栏、分组卡片、真实分组的目录空白与路径导航。悬停展开侧栏或进入书架目标，边缘滚动；取消／保存失败恢复临时浏览位置。
- Cmd/Ctrl+X 剪切，Cmd/Ctrl+V 粘贴移入当前或聚焦的真实分组；菜单提供等效动作，剪切项轻微淡化，电子墨水以虚线区别。剪切只记录本会话的身份与来源归属，不复制文件、不另建书籍记录，失败保留以便重试，Escape 清除待搬运状态。作者、系列和标签不被解释为文件夹目的地。
- 「用所选项目新建分组」或 Cmd/Ctrl+Alt+N 使用既有原位输入，新建和归置一次提交、一次撤销；冲突名称沿用编号规则。Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 或 Ctrl+Y 重做，名称输入内仍使用系统文字撤销／剪切／粘贴。
- 拖放／粘贴提交前重新核验被选书籍与完整分支成员、目录结构。过期来源不凭旧路径猜测；保存等待期间的新个人字段合并保留。四层、循环、同名处理与旧深层路径可读的边界不变。

## 正式接入与验收边界

2026-10-20 补充：文件夹导入始终以原文件夹名建立根分组；平铺选项只合并内部子层级。后续监听在设备设置中保存目的分组，分组重命名、移动、删除及安全撤销同步映射该目的地；同机窗口同步明确变更，跨设备备份不携带源路径映射。首页网格／列表可从空白处鼠标框选，修饰键追加，Escape 恢复开始前选择；拖动已选书交给同一批量移动与撤销链路。选择框使用主题墨色细线与淡底，电子墨水仅边框，不增加常驻操作区。

侧栏、书架及移动目标面板已接入同一分组保存链路。菜单补齐重命名、新建子分组、移动与删除；标题菜单和 Cmd/Ctrl+Shift+N 提供新建，菜单或 Cmd/Ctrl+Z 撤销，输入框保留系统文字撤销。四层校验覆盖原生目录导入、菜单移动、整分支拖动和目的地预检。顺序仍保存在现有 `libraryFolders` 数组，书籍仍沿用 `groupName` / 路径哈希，不改变个人云同步协议。

书籍变更通过现有书库持久化服务保存，先保存目录再保存受影响书籍；失败恢复目录，成功后才更新可见归属。重命名、移动与删除映射当前分组页面，失焦保存不抢走随后点击的导航。多步撤销／重做跨侧栏／书架共享，仅在分组目录与受影响成员仍匹配时执行；相关分支新成员或同步改组使旧恢复失效，后续书名和阅读进度保留。历史与剪切仅在内存中，不跨重开保存；目录与书籍的跨文件崩溃原子性未在本轮重构。

工程验收与最新结果见 `PROGRESS.md`。Chromium 鼠标、触控模拟和测试持久化适配器的结果，不等同于系统 WebView、真实触屏设备、多个应用窗口同时同步或断电重开的验收；上述边界继续单独核对。不得修改真实书库来制造验收结果。
