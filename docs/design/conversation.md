# 基础对话（2026-09-12）

本次用户明确要求取代以下旧设计。当前实现以普通 API 聊天为主，自动附带信息只有书名、作者和当前完整目录层级路径，且不在对话界面显示。正文提取、选区附件、范围、检索、预算、来源分类和摘要处理全部退出对话。完整当前规格以根 `PLAN.md` 的“对话方案（2026-09-12）”为准。

界面使用 Glossa 纸墨色、共享线条图标与安静的侧栏布局。顶部会话选择和新建/删除，下方消息与固定输入框；不加入注释说明，也不渲染书名、作者或目录路径。输入框内的模型入口支持服务选择、搜索模型、手动输入模型及设置。消息支持 Markdown、复制、重新生成、停止、错误重试、本机历史恢复与会话独立草稿。

目录路径由本地 EPUB 目录层级恢复（含扁平 NCX 的有限层级还原），按“父级 › 子级”拼接后随请求发送；目录不可用时回退到当前分节标签。新消息使用 conversation-3。沿用原数据库并保留旧记录的读取校验；旧原文/来源/摘要不会被带入新请求。模型只能看到三个元数据字段与当前会话有界的普通消息，不获取阅读正文。停止保留部分文本；仅完整轮次参与后续请求。导读的来源验证和阅读/同步数据保持原有行为。

## 上下文选择

| 选择 | 实际读取和边界 |
| --- | --- |
| 当前页（默认） | 使用阅读引擎实际可见 CFI，在原始文档中裁剪到可见文字；不扩展到段落的未显示尾部。 |
| 所选文本 | 只使用读者主动选择的原文；选区可独立附加于其他范围。 |
| 一段 | 从当前页涉及的段落中选择一个，明确扩大到完整原文段落。 |
| 一节 / 一篇 / 一章 | 读者从原书目录选择结构条目；按目录的起止锚点读取，包含该条目的子层级。支持最多组合四个目录条目，移除单个条目后只检索剩余范围。三种名称表达读者意图，不假设 EPUB 目录具有统一篇章语义。 |
| 全书 | 扫描本地线性阅读内容，按问题检索少量相关段落；宽泛问题采用分布式样本。取样不代表完整覆盖。 |
| 仅书籍信息 | 不附加阅读范围；“仅使用书籍信息”按钮同时移除选区和追问材料。书名、作者、章节标题和阅读位置仍携带。范围下拉切换仅关闭范围，独立选区附件仍须单独移除；预览显示最终结果。 |

扩大到节、篇、章、全书时显示可能包含未读内容。目录缺失时不虚构章节，可用当前页、选区、段落或全书范围。AI 无法从未提供的部分得出书中事实，应明确缺少的证据。

较大范围先做本地关键词排序，支持中文双字词及 Unicode 词语；选中来源保持原文顺序。单条目初选最多 6,000 字符，多条目合并去重后连同选区最多保留 8,000 字符候选、100 个来源。实际发送按轻量 2,000、均衡 4,000、扩展 8,000 三档预算筛选，默认轻量；选区优先，宽范围按问题相关性筛选。用户可取消任意片段；超预算的完整块明确标为未发送，不截取为假完整来源。全书最多八个片段，且不会发送全部原文来源。超长完整结构块不能容纳时跳过并显示部分证据，不截断冒充完整来源。用户每次发送都有固定的原文快照，随后翻页不会改变在途请求。

## 答案与来源

- 默认 2–4 个简短段落，结构最多八段，每段最多 1,400 字符。每个完整段通过结构与来源白名单校验后才显示；最终结果再次校验后保存。
- 原文依据与解释推断必须附已提供来源；背景知识单独标记，不能冒充作者观点；无法回答的原书问题标为证据不足。
- 模型只返回来源 ID，不生成可信引文、页码或位置。点开来源后在本地恢复锚点并核对原文；唯一匹配的局部引文允许恢复，歧义或失配明确报错。
- 支持跳到原文及返回读者实际起始位置，导航串行可取消。选区 CFI 转为文本节点边界，避免阅读引擎将元素边界还原为空选区。
- 全部正文、书名和历史属于不可信数据；提示词中明确不接受其中的工具指令。没有网络检索或自动工具执行。

## 历史、模型和失败状态

通过现有 provider 与安全密钥存储调用模型；界面可进入现有模型设置。对话使用独立 IndexedDB `glossa-conversations`，按文档哈希隔离，不迁移旧 AI 笔记数据库。每书最多 20 个对话、每个 40 轮，达到上限明确提示新建或删除；不会静默丢弃旧结果。

历史仅取最近四个符合当前模型与当前证据范围的回合，每轮问题最多 240 字符、摘要最多 500 字符。来源退出当前授权范围后，其历史摘要也不会发送。界面显示本次摘要轮数与全部摘要内容，可单独关闭。成功回答后固定本轮实际材料，连续追问不会被翻页或新问题检索结果悄然换题；用户可主动换用当前阅读内容或调整材料，旧摘要不绕过新的来源边界。不以无限历史维持连续性，也不将历史视为原文证据。

上下文读取、生成和来源导航均可取消，关闭或切离对话时中止。准备新上下文期间禁止发送过期快照。失败保留问题和已完成回答；保存失败保留内存中的有效结果并可重试，历史加载失败禁止以空历史覆盖。会话仅保存在本机，不改变云同步协议。每轮新增可校验的上下文记录，包括实际发送的书籍信息、范围、预算、来源标题、选区标识和压缩历史；重开、切换或主动复用历史材料可恢复追问焦点。旧 conversation-1 数据兼容读取，新提示词版本为 conversation-2。

## 验证边界

自动化使用原创 EPUB 和模拟模型响应。验证实际 Foliate 选区、来源恢复、返回阅读位置、范围隔离、连续追问、取消与本地保存，以及浅深色、320/420px 面板、RTL 和电子墨水。具体检查结果记录于 `PROGRESS.md`。

首版只对 EPUB 暴露入口。真实服务响应速度、章节检索召回、宽泛全书问题的覆盖率与阅读理解效果仍需实际使用验证；测试通过不代表模型观点一定正确或全书证据已充分。

## 上下文区交互与用量（2026-09-11 重构）

- 常驻层：书籍身份与当前阅读位置；元数据缺失时显示未知，不能让模型按标题猜书中内容。进度表示阅读位置，不代表全部前文已读。
- 调整层：“调整材料”折叠入口包含范围、多个目录条目、预算和用量说明。正文片段另有可展开清单，标明来源、选择原因及实际是否发送，可逐条排除和本地核对。
- 追问层：成功回答后保留发送快照；阅读位置变化只更新常驻元信息。每轮“查看本轮材料”保存发送时快照，不被随后翻页改写。“用这些材料继续”显式恢复历史材料，“换用当前阅读内容”回到当前页并清除选区附件。
- 默认不调用模型生成摘要；最多四轮，每轮问题 240 字符、回答摘要 500 字符，来源或模型不匹配即排除。只展示并发送当前允许的摘要。每次请求的原文预算在 provider 边界再次校验。
- 原文预算不是总 token 数或价格。书籍信息、系统指令、问题和摘要另计，输出上限 16,384 token；实际费用以模型服务为准。没有新增自动重试或自动模型调用。
- 设置和材料区可独立滚动，输入框保持在底部。保留窄屏、RTL、电子墨水与键盘交互。
