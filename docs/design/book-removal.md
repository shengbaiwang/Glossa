# 书籍删除、恢复与清理

产品目标：普通删除可恢复，彻底删除才清理数据。单本、批量、详情、最近阅读、书库和整库入口必须使用相同语义。

## 界面与操作（2026-10-26）

- 确认框只突出操作标题、目标书名、简短后果与取消／执行按钮。单本不重复显示选择数量，批量名单可滚动核对；具体清理类别按需展开，无法恢复的后果与实际同步范围保持直接可见。
- 普通与彻底删除按钮均使用红色，电子墨水使用黑白对比。详情删除以图标和文字放在全部内容底部，应用内菜单删除项置底；点击仍直接进入同一确认。清理本机下载放在现有更多菜单，标题与执行按钮明确写清理下载。
- 最近删除采用简洁书目列表，书名／作者／格式与恢复、彻底删除操作对应。单本无需先勾选；选中后才显示批量操作，保留键盘与触屏路径。成功恢复后有简短结果并将焦点移至页面标题。
- 未完成操作以带数量的可展开区域呈现；保留编辑只在确有草稿／读取异常时出现，并按需展开比较和恢复。旧共享数据主动检查归入「设置 → 书库与同步 → 数据 → 存储清理」，不混入日常删除列表。
- 正常成功只报告具体结果，不罗列为零的失败／未执行计数。失败仍保留所选与逐本原因，可在原位重试。提供停止时必须传递真实中止信号，停止后等待必要的单本保存结束；不可取消的提交不显示虚假的停止按钮。
- 对话框使用共享纸墨表面，按钮不缩放跳动；默认取消焦点，Escape、Tab 焦点约束及返回焦点保留。窄屏、深色、RTL、电子墨水与 44px 触控目标分别验收。

## 操作含义

- 删除分组只解散归组，保留书籍及其个人记录；选中分组不隐式选中内部书籍。
- 删除书籍移入「最近删除」，保留应用副本、外部原书、进度、笔记、对话、导图、目录与侧存；支持即时撤销、重启后恢复。
- 清理本机下载只释放当前设备的应用副本，保留个人数据和云端文件。外部文件不属于应用下载；不能只凭旧上传时间断言仍有可恢复副本。
- 清理前完整比对实际托管文件与可恢复的外部原文件或云端字节，清理前再核对本机内容。核验与重新下载使用相同的固定目录、格式和文件选择顺序；首个可下载镜像内容不符时不能用后续镜像正确代替。流式核验临时文件与阅读副本隔离，中断重试只清本书临时目录。
- 彻底删除从「最近删除」主动执行，明确列出书名、数量、应用副本、个人数据、缓存和实际同步服务；外部原始文件始终保留。

## 持久操作

删除服务先在共享书库写入边界保存完整目标集合和操作编号，再逐本清理。每本记录本机 pending / complete / failed，云端按服务分别记录回执；本机成功不能代表云端成功。重试复用原编号和目标，不重新扩展当前选择；后续恢复或新任务不能改变前次任务的计数。

取消只停止尚未开始的书籍。已开始的单本清理结束后保存结果；反馈分别显示完成、失败与未执行，失败和待执行项在重启后仍可继续。文件清理或最终记账失败时保留意图，重复执行必须安全。

失败任务逐本显示书名和可行动的原因，至少区分没有核验到相同恢复副本、本机文件变化与存储失败。原因属于本机执行回执，不发布到其他设备；成功重试清除旧原因。

恢复只读取并修改最新记录的生命周期字段，不能写回删除前的个人数据快照。显式恢复、重新导入和普通编辑使用不同路径；普通保存和上传不得清除删除状态。

## 并发与同步

删除／恢复时钟独立于阅读进度和元数据时间。旧窗口保存时保留较新的删除状态；删除后出现的新个人编辑保留为冲突，由用户恢复或再次确认彻底删除。

文件同步以不可变的操作记录补充共享书库索引，避免旧索引覆写使书籍重新出现。破坏性远端清理前重新核对本机状态与对端最新操作；遇到恢复、冲突或无法核验的记录停止清理。冲突元数据保存成功而笔记拉取失败后，后续同步仍须重试笔记。

个人数据写入和彻底删除共用每书的独占边界。持久删除屏障先于文件清理；已在途写入先结束，然后清理，迟到的旧请求不得重新创建文件或数据库记录。重新导入更新写入代际，不能让旧窗口恢复写入权限。显式个人编辑与旧异步请求须区分：拦截旧请求不能成为丢失新编辑的理由。

主动编辑在用户动作发生时记录独立编号和高精度时间；删除屏障记录本机阻断时间。晚于阻断的新笔记、对话改名、导图修改和新提交问题写入独立的持久冲突草稿，不写回原数据。旧异步回答、目录／页码补写和删除前已提交的任务不能凭保存时的时间变成新编辑。阅读器始终携带打开时的写入代际，不能借用另一个窗口较新的恢复记录。

草稿按编号保持不可变；重试不复制，另一窗口的新草稿单独保留。最近删除可重新读取、导出和逐项确认丢弃；确认后出现的其他草稿不在本次丢弃范围内。书籍恢复或重新导入后，在原行展开当前记录与保留草稿的比较，再主动恢复独立副本。笔记追加独立编号，对话和导图复制为单独会话／工作区条目，保留当前内容及不可变原始来源；未发送问题仅恢复为对应复制会话的输入草稿，发送前不运行模型。

恢复在书库锁及每书写入锁内重新核对生命周期、不可变草稿和当前记录；内容变化须重新比较。先验证合并后数据、容量和来源，再建立新写入代际、保存书库并提交副本。书库保存失败撤回临时屏障；副本写入失败保留已发布代际和草稿，使当前记录仍能保存。副本编号由草稿编号确定，重试不重复添加；仅在成功后移除本次草稿，其他草稿保留。读取失败或损坏记录不得按空数据覆盖。

## 数据清理边界

- 托管原书、封面、配置、导航及每书音频缓存按稳定书籍身份定向清理。
- 对话、已保存导图和编辑工作区按记录中的 bookId 定向清理，保留其他书籍和旧学习笔记。
- 新的观点清单、导图任务检查点和 PDF 目录备份记录书籍身份及写入代际。旧记录只有在精确任务键与内容校验通过后才能补归属；不能凭观点、标题或相似来源猜测。
- 原生 PDF/OCR 侧存以书籍身份、写入代际及完整原文件指纹建立私有目录和归属清单；旧共享侧存在经过原文件核验的读取时复制迁入，保留原有 OCR 与个人目录。新代际可从同书同文件的最近完整代际迁入，失败复制可重试。原文件缺失不妨碍按归属清单删除；同一 PDF 的其他书籍目录保留。
- 原生删除先持久化阻断账本，再停止并等待本缓存的 OCR／导出子进程退出，之后移除全部目标代际目录。打开缓存、保存目录、OCR、导出发布均检查账本，迟到旧请求不能重建。较新显式恢复可重新建立代际，较旧删除不能清除它；清理本机下载仍保留侧存。
- 无法归属的旧共享缓存使用独立「检查旧共享数据」入口：浏览器只检查旧生成清单、检查点及目录备份；不猜测归属或删除旧个人对话、导图和学习笔记。原生检查旧 PDF/OCR 目录。确认须显示记录／目录数量，明确影响所有使用它们的书籍，包含旧 PDF 识别文字及已保存目录（含个人目录），且不可撤销。
- 旧共享清理固定检查时的目标及内容快照，执行前重新核验。已改变或已取得书籍归属的记录须重新检查；后来新增的记录保留，已不存在的目标可安全重试。原生清理同样停止活动写入并持久阻断旧请求，浏览器异步补归属须在事务内重读，不能重建已清除记录。单书彻底删除确认如实说明只清理可核验归属的数据，旧共享数据另行处理，不能把共享残留表述为已经清除。

## 验收要求

1. 单本、批量和各入口一致；分组解散不删除内部书籍；触屏和键盘均可操作。
2. 普通删除后撤销、重启恢复、后续改名和阅读进度保留；恢复不依赖旧界面快照。
3. 先持久化再清理；保存失败、单本清理失败、取消、中断、重试和重复执行均有对应的真实结果。
4. 全部已承诺的数据类别完成定向清理，外部原文件及其他书籍不变；并发旧请求、封面选择、缓存写入和原生流式下载不复活已清理副本。
5. 跨窗口、对端恢复、较旧客户端写入、同步失败和各服务回执分别验证；冲突数据可持久恢复和由用户处理。
6. 确认内容与实际目标一致，失败可重试，默认焦点安全，焦点恢复、44px 触控目标及电子墨水边界可见。
