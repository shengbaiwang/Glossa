# Glossa 导图：观点的纸上脉络

日期：2026-09-13。用户明确要求从品牌出发，先做好基础功能，再考虑接入 AI。本节为当前规格；文末保留早期生成方案供兼容维护。

## 使用与视觉

导图位于 EPUB 的右侧栏，打开只读取本机数据。空白页从一个主题开始，没有模型配置和生成步骤。大纲负责连续输入，导图负责看清父子关系；两种视图共用同一棵有序树。

沿用 Glossa 的纸墨主题、圆润线条与留白。根主题用字重和边框建立重心，观点以中性色显示；可选关系词作为较轻的行间文字，表达“支持、因为、限制、例如”等联系。没有预填的 AI 内容、彩虹分支、来源角标或解释卡片。大纲用细竖线衔接层级，水平导图自动安排分支位置；长文字换行，画布在自己的视口内滚动。

- 每本书可新建、切换及删除导图。根节点文字即名称。节点可编辑内容及关系词，添加同级/子级、升降级、上下移动、删除整条分支；根节点不可删除。
- 大纲单击即编辑，导图单击选择、双击或“更多 → 编辑观点”编辑。折叠按钮独立；折叠后显示隐藏观点数。
- Enter 新增同级（根上新增子级），Cmd/Ctrl+Enter 新增子级；文本编辑时 Tab/Shift+Tab 降/升一级，Alt+上下排序，Shift+Enter 换行。F2 编辑，观点按钮上的方向键浏览，Delete 删除分支；中文组字期间不触发结构操作。Cmd/Ctrl+Z 撤销，Shift+Cmd/Ctrl+Z 重做。
- 按层展开、单支聚焦、面包屑返回；查找包括折叠节点，选择结果后展开它的祖先链。缩放 40%–160%，支持适应、恢复原始比例、滚动与空白处拖动画布。展开工作区使用原生 modal dialog，Escape 可逐步结束编辑、关闭查找或返回侧栏。
- 操作区与画布分离。窄栏保留完整控件并换行，侧栏滚动不扩大阅读区；RTL 采用逻辑方向连线，深色和电子墨水沿用现有主题。展开视图不更改阅读内容和原生窗口布局。

## 本机数据与恢复

新模块 `workspace.ts` 定义手工有序树与视图状态；每书最多 20 图，每图 200 节点、12 层，文本 500 字符、关系词 80 字符。运行时拒绝重复 ID、多根、断链、环、无效视图引用、越界和未知字段。手工节点没有来源身份，不声称代表作者原文。

`workspaceStore.ts` 使用独立 IndexedDB `glossa-map-workspaces`。每书一条版本化记录，保存内容、当前图和各图的视图/折叠/聚焦/选择/缩放。写入在同一事务中比较修订号后替换；旧记录损坏或窗口冲突时不覆盖。数据库空间不足及其他写入异常回滚。

`workspaceSession.ts` 在同一应用页面内按书共享状态，串行写入并合并在途修改，侧栏关闭后仍完成保存。保存失败保留内存内容、撤销历史和重试入口；未保存时提供离页保护。最多 50 步撤销/重做保留到本次应用会话结束，不是跨重启的版本库。系统强制退出前尚未落盘的内容不能保证保留。

备份下载保留本书所有手工导图；导入先校验 JSON（最大 5 MB），再在当前书内新增副本，原有图保持不变，导入可撤销。多窗口冲突后的当前修改可先下载，再重开应用并导入，不自动合并冲突。

历史生成图通过“此前生成的导图”按书只读加载，保留原协议及来源校验，文字点击必须核验本地来源后才导航，失败不盲跳，支持返回阅读位置。旧数据库不迁移、不删除，历史生成模块只保留兼容代码与测试，当前 UI 没有生成入口。

## 验收与后续

使用原创中文树和模拟错误验证：相同节点在双视图中保持层级，整分支调整/撤销，持久化重开与书籍隔离、损坏/配额/冲突保护、备份恢复、旧图来源导航，以及真实浏览器中的无重叠布局、窄栏、展开窗口、深色、RTL 和电子墨水。

AI 接入、语义提取质量、自动来源绑定与真实阅读收益另行设计和评测。本轮不增加正文提取、模型请求、同步或图形依赖，不改变简单对话边界，导读保持移除。

## 学习价值与取舍

概念图的价值在于明确关系，而不只是把摘要放进方框。2018 年发表的[概念图元分析](https://link.springer.com/article/10.1007/s10648-017-9403-9)汇总 142 个效应量、11,814 名参与者，报告总体 g=0.58；制作图与阅读图分别相对各自对照的效果为 0.72 与 0.43。两类任务的研究并非同一随机比较，不能据此认定“制作必然优于观看”，也不能推导出 AI 自动生成图的学习增益。[Karpicke 与 Blunt 的实验](https://pubmed.ncbi.nlm.nih.gov/21252317/)还表明，其研究条件下提取练习优于概念图精加工。因此，本功能的工程目标是帮助看清结构、核对原文并继续阅读；不宣称提高记忆或替代主动思考，不恢复测验功能。

## 阅读交互

EPUB 的右侧 Notebook 增加“导图”，桌面与正文并排，来源跳转不会自动关闭；小屏沿用既有可关闭面板。打开只列本地目录，选择章节才提取，选择阅读段并按生成才请求模型。生成前可核对范围和使用的服务；生成后收起范围与模型控件，保留章节、阅读段选择及导图。

每个节点是短语，父子关系用短动词或关系词标明，不强行把叙事变为因果论证。默认展开根的下一层，读者可逐层/全部展开与收起、调整字号。节点文字直接打开其首个来源对应的段落所在页；EPUB 页码随排版变化，因此使用可恢复 CFI，绝不由模型编造页码。单独的加减按钮只改变折叠状态。

图面没有来源编号、角标或解释卡片；解释放在悬停提示中，理解性解释明确标为“理解性解释”。来源多于一处时，首个来源为主要跳转处，其余来源保留在已校验数据内。本次没有独立多来源浏览器。来源失效不盲跳，而是显示错误和本机保存的未核验摘录。点击后可返回原阅读位置。

节点与控件采用 Glossa 的纸墨主题变量、12px 圆角、细线和留白，无渐变、阴影或装饰性色组。树随侧栏换行，不做无限画布。保留 44px 操作目标、键盘焦点、RTL 逻辑连线与电子墨水边框。保存成功通过无障碍状态播报，不占据图面。

## 数据与实现

- `glossa/mindmap` 独立管理生成、协议和存储；UI 不直接调用厂商 SDK。
- 使用 `ReadingPassagePanel` 和独立 `glossa/passages` 模块 的明确选段、生命周期、取消、模型配置和来源导航；简单对话仍只自动带书名、作者和目录路径。
- 单次最多 20,000 字符、200 个原文来源，发送所选完整段及最小元数据，不发送锚点，不读取邻段/后文。仅显式长度耗尽时，以同一快照重试一次，沿用现有 provider 预算策略。
- `mindmap-1` / schema 1：节点上限 24、深度上限 4（含根）；ID 唯一、仅一根、无环/孤儿，每节点 1–4 个提供过的来源。标签最多 60 字符、关系 24、解释 300；拒绝未知字段和超过 32,000 字符的外部结果。证据不足只接受空图。
- `source` 表示忠实转述；`inference` 表示基于证据的理解性解释，包括推断的关系。模型返回的合法 ID 只证明引用存在，不证明语义蕴含；生成质量仍需实测审阅。
- 所有标签以 React 纯文本渲染，不执行 HTML、链接或脚本。导航前由本地来源解析核验结构和原文；文档内容始终是不可信输入。
- 独立 IndexedDB `glossa-reading-mindmaps`，键为书/章节/阅读段。缓存包括文档哈希、正文与锚点哈希、provider/地址/模型和版本；读取、写入都校验。旧导读/笔记数据库不打开或迁移。
- 仅保存最新有效图；原子事务失败或取消保留旧图。加载失败阻止覆盖，保存失败保留当前结果供重试。切换书籍/段落、关闭面板、模型变化取消在途工作，迟到响应不污染新状态。刷新页面前仍未保存的结果不保证保留。

## 验收边界

单元测试覆盖图协议、图深度/环/来源攻击、请求快照与取消、长度重试、缓存身份、面板加载/保存失败及关闭、分支直接跳转和折叠。真实 Chromium 使用原创 EPUB、模拟 provider 与真实 Foliate/IndexedDB，验证未选正文不外发、原文段落定位、返回、保存重开、浅深色/280px 窄栏/RTL/电子墨水。Notebook 回归验证标签切换、摘录草稿与阅读生命周期。

本轮没有使用用户书籍或真实模型，不能宣称速度、中文生成准确度、WebView 兼容性或学习收益已验证。当前切片不含 PDF/网页、整章自动串行生成、整书图、自由编辑、图片导出与同步。下一步是在当前开发版以少量明确授权材料验证关系忠实度、点击定位与阅读负担；无需为此提前扩大产品范围。
