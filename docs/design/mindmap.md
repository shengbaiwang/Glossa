# Glossa 导图：观点的纸上脉络

日期：2026-09-13。最新授权为简洁的 AI 生成、编辑修改、原文跳转与文段核对。本节取代早先生成入口停用的安排；文末保留历史方案。

## 工作区与视觉

右侧「对话 / 导图 / 摘录」同属一级导航，以统一墨色下划线标明当前页；关闭直接可达，固定收进右栏菜单，摘录搜索仅出现在摘录内。导图标题与操作属于二级，内部大纲/导图以较轻的分段按钮切换，避免重复标题和多排同等强调的标签。

导图使用 Glossa 纸墨色、共享圆润线条图标、12px 圆角和安静留白。大纲连续排列观点，以细竖线衔接；水平导图采用墨色根主题与细连线，分支以文字为主。长标签自然换行，画布只在自己的视口滚动。没有教学式小字、彩虹分支、来源编号或解释卡片。

打开只读取本书本机工作区。空白页仅显示「生成导图」「新建导图」，手工图可独立使用。AI 生成表单中明确选择章节及阅读段，核对首尾原文和服务；生成操作不会扩展到邻段或后文。生成完成自动进入可编辑大纲，旧图可主动建立编辑副本。

## 基础编辑

- 同一份有序树驱动大纲与导图；根观点即图名。文字、关系词、子级/同级、升降级、上下移动、整分支删除及折叠均可用。
- 有来源节点单击打开原文；无来源节点在大纲内单击编辑、导图内单击选择。双击、F2 或底部编辑按钮均可编辑，完成按钮结束输入。输入框随文字增高，关系词保持可选。
- 编辑时 Enter 新增同级（根节点上新增子级），Cmd/Ctrl+Enter 新增子级；Tab/Shift+Tab 降/升一级，Alt+上下排序，Shift+Enter 换行。浏览时 Enter 打开当前节点原文或进入编辑，方向键浏览，Delete 删除当前焦点分支，Cmd/Ctrl+Z 撤销、加 Shift 重做；中文组字不触发结构操作。
- 标题旁导图菜单包含新建、查找、按层展开、历史图、备份和删除导图；底部观点菜单包含升降级、排序、聚焦和删除分支。扩展工作区与撤销/重做在视图工具栏。画布缩放/适应只在导图视图出现；保存成功通过无障碍状态播报，错误提供重试。
- 既有搜索隐藏节点、祖先链展开、聚焦路径返回、40%–160% 缩放、适应和平移继续可用。扩展视图使用原生 dialog；来源跳转成功后收回侧栏。窄栏、RTL、深色和电子墨水遵从同一套视觉变量和交互目标。

## AI 生成与原文

单次只发送明确选择的完整阅读段，最多 20,000 字符/200 来源。现有 provider 接口隔离厂商访问；关闭、切换段落或模型时取消，未选段不发送正文，简单对话仍只携带书名、作者和目录路径。

新提示词 `mindmap-2` 优先生成 5–10 个短观点、2–4 条主分支和 2–3 层；硬上限继续为 24 节点/4 层。保留限定条件、例证范围、同级粒度与原文支持的关系；不强行制造因果。每节点 1–4 个已提供来源，首项是主要原文。显式输出截断时仅重试一次并压缩结构，两次均遵从用户配置的输出上限。

生成结果通过结构和来源白名单校验后成为可编辑 `LocalMap`。不可变的 `origin` 保存原始生成记录，节点通过 `originNodeId` 关联；标签、关系、层级修改只作用于工作树。新增手工节点没有这个关联。原文区将已修改观点标为“已编辑”，未改写推断标为“理解性解释”；这不等同于证明生成观点的语义准确。

点击节点后由 `resolveSource` 重新读取本机原文，校验成功才通过 `navigateSource` 跳转。底部原文区显示本机核验得到的完整文段，而非模型解释。多个来源可用前后按钮切换，不在图上加编号；可关闭文段并返回原阅读位置。核验失败不盲跳，只展示标为未核验的保存文段，并可重试。快速切换节点、关闭或换图取消旧请求；旧结果不得覆盖当前文段。选择手工节点时清除上一个来源展示。

## 本机保存与兼容

每书最多 20 图、每图 200 节点/12 层；文字最多 500 字符、关系词 80 字符。工作区 `version: 1` 向后兼容地增加可选原始记录和节点关联；严格拒绝多根、断链、环、无效视图引用、越界、未知字段和跨书来源。存取同时校验来源快照内容与缓存哈希，保留 mindmap-1 的旧身份计算，新提示词仅使后续生成缓存更新。

`glossa-map-workspaces` 存储编辑树和视图状态，`glossa-reading-mindmaps` 保留原生成记录；旧库不迁移、不删除。新生成图在原库保存尝试后交给工作区独立保存，即使原库保存失败也不丢弃有效结果。工作区加载失败禁止覆盖，写入失败保留当前修改并提供重试，跨窗口修订冲突阻止覆盖并允许下载备份。

`workspaceSession.ts` 在同一页面按书共享状态，串行原子保存并合并在途修改，侧栏关闭后仍继续。会话内最多 50 步撤销/重做不跨进程重启；强制退出前未落盘数据不能保证恢复。JSON 备份先校验后新增副本（不覆盖现有图）；跨书导入剥离原来源身份。

## 学习价值与取舍

概念图的价值在于明确关系，而不只是把摘要放进方框。2018 年发表的[概念图元分析](https://link.springer.com/article/10.1007/s10648-017-9403-9)汇总 142 个效应量、11,814 名参与者，报告总体 g=0.58；制作图与阅读图分别相对各自对照的效果为 0.72 与 0.43。两类任务的研究并非同一随机比较，不能据此认定“制作必然优于观看”，也不能推导出 AI 自动生成图的学习增益。[Karpicke 与 Blunt 的实验](https://pubmed.ncbi.nlm.nih.gov/21252317/)还表明，其研究条件下提取练习优于概念图精加工。因此，本功能的工程目标是帮助看清结构、核对原文并继续阅读；不宣称提高记忆或替代主动思考，不恢复测验功能。

## 阅读交互

EPUB 的右侧 Notebook 增加“导图”，桌面与正文并排，来源跳转不会自动关闭；小屏沿用既有可关闭面板。打开只列本地目录，选择章节才提取，选择阅读段并按生成才请求模型。生成前可核对范围和使用的服务；生成后收起范围与模型控件，保留章节、阅读段选择及导图。

每个节点是短语，父子关系用短动词或关系词标明，不强行把叙事变为因果论证。默认展开根的下一层，读者可逐层/全部展开与收起、调整字号。节点文字直接打开其首个来源对应的段落所在页；EPUB 页码随排版变化，因此使用可恢复 CFI，绝不由模型编造页码。单独的加减按钮只改变折叠状态。

图面没有来源编号、角标或解释卡片；解释放在悬停提示中，理解性解释明确标为“理解性解释”。来源多于一处时，首个来源为主要跳转处，其余来源保留在已校验数据内。本次没有独立多来源浏览器。来源失效不盲跳，而是显示错误和本机保存的未核验摘录。点击后可返回原阅读位置。

节点与控件采用 Glossa 的纸墨主题变量、12px 圆角、细线和留白，无渐变、阴影或装饰性色组。树随侧栏换行，不做无限画布。保留 44px 操作目标、键盘焦点、RTL 逻辑连线与电子墨水边框。保存成功通过无障碍状态播报，不占据图面。

## 数据与实现

- `glossa/mindmap` 独立管理生成、协议和存储；UI 不直接调用厂商 SDK。
- 使用 `ReadingPassagePanel` 和独立 `glossa/passages` 模块 的明确选段、生命周期、取消、模型配置和来源导航；简单对话仍只自动带书名、作者和目录路径。
- 单次最多 20,000 字符、200 个原文来源，发送所选完整段及最小元数据，不发送锚点，不读取邻段/后文。仅显式长度耗尽时，以同一快照重试一次，沿用现有 provider 预算策略。
- `mindmap-1` / schema 1：节点上限 24、深度上限 4（含根）；ID 唯一、仅一根、无环/孤儿，每节点 1–4 个提供过的来源。标签最多 60 字符、关系 24、解释 300；拒绝未知字段和超过 32,000 字符的外部结果。证据不足只接受空图。
- `source` 表示忠实转述；`inference` 表示基于证据的理解性解释，包括推断的关系。模型返回的合法 ID 只证明引用存在，不证明语义蕴含；生成质量仍需实测审阅。
- 所有标签以 React 纯文本渲染，不执行 HTML、链接或脚本。导航前由本地来源解析核验结构和原文；文档内容始终是不可信输入。
- 独立 IndexedDB `glossa-reading-mindmaps`，键为书/章节/阅读段。缓存包括文档哈希、正文与锚点哈希、provider/地址/模型和版本；读取、写入都校验。旧导读/笔记数据库不打开或迁移。
- 仅保存最新有效图；原子事务失败或取消保留旧图。加载失败阻止覆盖，保存失败保留当前结果供重试。切换书籍/段落、关闭面板、模型变化取消在途工作，迟到响应不污染新状态。刷新页面前仍未保存的结果不保证保留。
