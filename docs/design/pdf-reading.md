# PDF 基础阅读

授权范围：2026-10-10 用户要求完善目录层级、全文搜索/复制、注释往返、续读/个人书签、高亮/笔记汇总。2026-10-16 授权本地 OCR 与目录修复；2026-10-17 授权视觉找页、区域摘取、连续性验收及便携副本，要求长期修复精确选字，随后明确以导入自动目录取代手动准备工作区，并要求新导入扫描书直接可选字。沿用 Glossa 工作区、本机存储及既有个人记录，不增加模型请求或 MCP。

## 导航与定位

- PDF.js 内置 outline 保留父子层级，支持零起始页索引、间接页对象和具名 destination。目录项具有稳定的页 CFI 与递归唯一 ID，供当前位置层级路径及笔记归组使用。
- 保留 PDF page labels（如前言罗马数字与正文阿拉伯数字）。导入时缺少可靠 outline 则尝试下述本机自动目录；未能核验时保留实际页码导航，不推测章节。
- 目录位置拆分同步返回页索引，适配现有导航/搜索接口；无效、不存在、越界 destination 不使阅读会话报错退出。
- XYZ / FitH / FitV / FitR 等 destination 使用 PDF viewport 转换并在已渲染文字层定位；没有文字时按页内比例定位。搜索、个人注释和续读使用既有 CFI Range。
- 分页和滚动模式均等待目标文字层就绪后滚到 anchor。内部注释链接及原有后退/前进历史共用这一路径。

## 文本、个人记录与恢复

- 全文搜索沿用逐页本机搜索；文字选择、跨行复制沿用 PDF.js 文字层与既有复制工具。不会把内置注释弹窗的文字混入可见正文摘录。
- 固定版式在导航和滚动结束时报告可见正文 Range。续读保留页内文字位置；个人书签保存可见摘录，固定版式同一物理页的旧页级 CFI 和新页内 CFI 可识别为同一书签，避免重复。
- 阅读位置仍采用延迟保存；关书时取消待执行计时器并立即保存发生变化的最后位置，再刷新书库记录。初次打开的未变位置和临时预览不重写续读位置。
- 高亮和笔记沿用本机 `BookConfig.booknotes`。缩放重建文字层后重新建立 overlay，现有 Annotator 从个人记录恢复高亮/笔记；不复用已经脱离文字层的旧 Range。
- 右侧笔记继续提供高亮/笔记计数、筛选、搜索、目录归组和原文跳转；左侧个人书签保持独立。旧记录不迁移、不清理，不向 PDF 原文件写入个人记录。

## 验收与边界

原创四页 PDF 夹具包含嵌套目录、混合页码、每页可搜索文字、跨行文字、双向内部注释链接和内置注释。真实 Chromium 使用 PDF.js 解析和渲染，验证目录跳转、层级路径、全文命中、页内定位、选文复制内容、个人记录筛选/归组、注释往返、书签匹配、缩放后的高亮和重开定位。确定性回归另覆盖无目录与坏链接、快速关书和临时预览不保存。

同页多个目录项的笔记归组按页级 CFI，不声称已恢复精确的同页章节边界。Chromium 验证不替代 macOS 原生 WebView 实机验收。

## 本地识别文字（2026-10-16）

- 首版仅 macOS 12 及以上的 Tauri 桌面端。构建时用系统 Swift 编译随包的 PDFKit／Vision 处理器，运行时直接启动经过字节校验的该处理器；不调用 shell、MCP、网络或外部模型，不要求用户安装 Python 或 OCR 工具。
- 导入自动目录仅在必要页面没有文字时启动识别；阅读器对已加载的无文字页面自动后台补字，整书识别放在现有书籍菜单，主动点击后才执行。PDFKit 按旋转后的 crop box 渲染不超过 3200px 的页面，Vision 返回中英文词／字的归一化坐标与原识别顺序。任何已有文字的页面整体跳过，避免改变旧文字层的 DOM 和 CFI；首版不补识别混合页中的局部图片。
- 原 PDF 不改写。应用本地数据目录 `pdf-local-v1/<完整内容 MD5>/vision-pdf-1/` 保存逐页 JSON 与进度，`outline.json` 独立保存个人目录及版本。前端严格校验坐标、文本长度及页号，只对无原生正文的 `.textLayer` 注入 OCR 字词；搜索与新选择使用同一版本化阅读顺序，旧节点只用于兼容定位，详见下节。页内搜索采用有界的 16 页读取缓存。
- 导入目录、阅读补字与菜单任务共享 WebView OCR 队列，原生忙时在调用方预算内等待，不窃取其他任务。原生每次启动返回独立任务标识，状态与取消均核对标识，迟到取消不能终止同书后续任务；调用方取消仍清理迟到启动，队列待其清理后释放。菜单任务连同排队最多 30 分钟。单进程串行任务，独立工作进程可取消；每完成一页原子保存，重试跳过已校验的页。批量导入的目录准备依次执行。菜单中的主动识别提供进度与取消，关闭菜单会取消该次任务；正常退出会终止处理器，已保存页可复用。应用／重开前校验当前文件指纹，源文件变化时拒绝继续复用。
- 当前阅读器可为已加载且无原生文字／OCR 的页面创建侧存并后台识别；先完成图像绘制，再向空文字层追加同一版本的 OCR 与兼容节点，保持已有节点和 CFI。全 WebView 串行、每页最多 30 秒，合并重复缩放请求；页面已移除则跳过排队任务，关书取消所属工作，失败显示明确状态且不自动重试循环。已有菜单任务只等待／复用，不取得其取消权。搜索、缩略图、导入解析与其他只读 DocumentLoader 不启动阅读识别。
- 补字完成按当前绘制代次发布，若新倍率在等待时使用空快照，完成绘制后补上已就绪文字；状态为 CFI 忽略节点。补字后发出文字就绪事件刷新高亮，不恢复旧滚动锚点。保留结束节点与 OCR 子节点顺序，使新选择保存的 CFI 重开后一致。主动整书识别成功后保存当前 CFI 与既有配置并重建阅读器；取消／失败保留已保存页，重开读取。
- 预算：文件最多 2GB／5000 页，单页 JSON 4MB／10000 个字词／100000 字符，单文档缓存约 512MB，开始前全体缓存低于 1GB，单任务 30 分钟。越界停止并保留有效进度，不自动扩展预算或反复重启。

## 精确选字与文字层兼容（2026-10-17）

- Vision 可按列返回标题和页码；直接采用返回顺序会使一行的原生 Range 包含下一行标题。显示时以纵向重叠／中心距离组合行，只有至少两行出现右侧分离页码及真实间隔时才启用目录排序。普通多栏保留识别块序，避免正文逐行交织。原词框、文本、偏移与引擎缓存均不改写。
- `.textLayer` 原有 span／br 顺序保持，标记 `data-pdf-legacy`、隐藏并禁用交互／辅助技术遍历，但保留实际矩形供旧 CFI 批注与导出求框。末尾添加稳定的 `data-pdf-ocr-text="2"` 阅读子树。新 CFI 与旧 CFI 分开；搜索遍历、可见范围、区域摘取及朗读只消费活动阅读层一次。未来改变该子树结构须再次处理持久定位兼容。
- 在当前字号下批量测量每个 span 的真实文字 Range，按完整宽高与顶部偏移缩放到 OCR 框，包含尾空格及 CJK 字体度量。字体大小不再被当成浏览器选区高度。保留规范化坐标，旋转与缩放仍由同一 PDF viewport 决定。
- 部分 Chromium 在已滚动、裁切的 iframe 内误判变换后词首为词尾。仅 OCR 活动层的主鼠标拖选使用字框与字符 Range 几何命中，以 `Intl.Segmenter` 字素边界避免拆开代理对／组合音标；继续输出真实 Selection／Range，支持反向拖动、Shift 延伸、双击词选及键盘调整。指针捕获、取消、Escape 与失焦清理拖动；每次重绘中止上次监听器。触屏初始选字、原生文字 PDF 及主动关闭选择的即时批注仍走既有路径，PDF 端点句柄另复用下述跨页协调器。
- 页面绘制取消旧 canvas 与 TextLayer 任务，使用隐藏、不可交互、CFI 忽略的暂存层。画面与文字都就绪且代次仍有效时才同步替换；失败保留此前可用内容，暂存节点与未使用画布清理。旧异步绘制不得向新层追加文字。
- 持久回归使用原创中文目录及真实原生／扫描 PDF：实际鼠标正反拖、精确词内字符、75%／100%／150% 字框、放大并滚动后的选字、键盘调整、连续被替代的缩放、搜索去重、朗读去重、新旧定位与高亮重开。独立系统 WKWebView 使用真实 AppKit 鼠标事件验证同一 OCR 模块及 CFI。截图仅辅助检查，不能取代选中文字和几何断言；跨页拖选的实现与验收边界见下文，复杂多栏／竖排／双向混排和 OCR 识别错误仍需另行验收。

## 导入时自动目录（2026-10-17）

- 移除侧栏的识别／修复／应用工作区，不再要求指定目录页、输入页码偏移或确认草稿。macOS 本地 PDF 完成持久导入后、释放解析器前执行；复用导入加载状态。临时预览、普通开书及其他格式不触发目录准备；普通阅读页按上述规则补字。
- 首先保留既有个人目录，包括主动清空或恢复原目录的旧记录；当前版本已核验的自动目录可按文件指纹复用。内置目录逐项核对实际目标页的完整标题行，无文字目标按需精细 OCR，准确时保留原层级与原页内定位，不扫描整本书。
- 否则先以最多 4 个原 PDF「目录／Contents」书签为未可信线索；全书原生文字与已有精细 OCR 优先找真实目录，无线索的扫描页按最多 16 页一批、最长边 1200px 的低清 Vision 识别渐进检测，不依赖固定前置页窗口。低清结果单独保存在 `vision-detect-1`，只提供候选与版面线索，不注入阅读层、不用于最终标题核验，也不进入导出文字。发现目录后只精读该页、连续目录页及结束边界页；原生文字用 PDF.js 字框重建行，必要无文字页使用原有精细 OCR。标题列与页码列按实际纵向重叠及横向间隔配对，支持引导点、全角数字与罗马页码，不修改 OCR 原字词或旧定位。
- 优先明确标有「目录」的页面，避免此前出版信息／日期误触发；插图／表格目录不作为章节表延续。页码前的扫描点／冒号在确有列间距时规范化。命名目录中的同字号标题即使短页码漏识别也不能丢弃：独立匹配实际标题，重复页眉只有明确的内部标题留白证据才可消歧，否则整体回退。章号单独成行时可与下一标题行共同核对。
- 先按 PDF page labels／印刷页码定位，罗马与阿拉伯编号、印刷编号重新起算分别分组，不对前言和正文强套同一偏移。由不同标题的命中提出组内偏移，每个目标仍通过同一核验函数；目标错位时低清命中仅提名候选，精细 OCR 须有独立内部标题版面。存在多个有效解释时拒绝发布。所有条目均须在有效页面、顺序一致，且目标页存在匹配的完整标题行；目录来源页不能证明其自身是章节目标。不发布未核对条目或部分目录。
- 没有印刷目录时，完整低成本检测全部页面后，只精读并核验页首明确编号的中英文章标题。重复页眉去重，同类编号须从一连续递增，缺号或候选无法核验不发布部分章节。无足够章节证据不生成；模糊标题、跨行标题、复杂多栏与识别错误可能回退页码，不承诺任意材料均成功。
- 目录续页保留漏页码标题，紧贴数字、单个 OCR 引导点与单字中文标题仅在已确认目录中解析；日期分部不误作页码条目。先识别并核对印刷页码指向的页面，再以唯一的独立内部标题纠正前置页混合页码，OCR 重新定位须有明显标题版面，不能误用页眉。末页即使页码均紧贴标题也不得提前截断。标题尾部脚注圈码可忽略；仅 OCR 的前十行、章号完全相同、标题至少八字且只漏一个汉字时允许七字以上独立匹配，不接受替字、错章号及短标题模糊匹配。
- 自动准备最多 1000 文档页（最多逐页低清检测）、96 个新增精细 OCR 页、128 项、200 万字符、180 秒；沿用原生文件／空间上限。失败或超限保留有效 OCR 页及导入的书籍，提示可继续按页码阅读，不循环扩预算。自身预算耗尽仍保存安全页码后备，用户取消不写目录。错误内置目录在可保存时记为页码后备，重开不恢复错误链接；重新明确导入可重试自动发现。
- 侧存生成器标记为 `glossa-contents-3`／`glossa-pages-1`，旧记录默认为个人目录；完整的第二版结果仅复核目标并升级标记，无须重新找目录。核验复用现有有界派生存储 `glossa-pdf-contents`：最多 16 本、每本 128KB、总计 2MB，按文件指纹及页数绑定，逐项保存标题、页索引与文字／原生或 OCR 类型摘要，独立核验版本为 `pdf-heading-2`。缓存故障回退正常核验；取消或失败后已完成条目可在下次导入复用，摘要／核验版本变化必须重做相应检查。低清与精细识别使用独立侧存版本，路由升级不重做识别；完整内容指纹、修订号比较与原子替换拒绝源文件变化及其他窗口的并发覆盖。原始 PDF、个人书签、高亮、笔记、书籍哈希与同步协议保持原样；已核验目录可随阅读副本导出。

- 提取器 `pdf-contents-5` 识别目录标签两侧的页码及分行「目／录」，以独立 Illustrations／Figures／Tables／Maps／Plates 等标题终止章节表，目录本身列出的 List of illustrations 条目仍保留。罗马 Part／Chapter 章号与下一行合并；中英文完整标题可跨行核对，不静默丢弃缺页码条目。明确分隔的中文序号及「衞／衛」仅做确定性匹配；不把 OCR 替字当作正确原文。长书按页缓存规范化后的精确标题集合，不在每个条目上重复规范化全书文字。
- 在明确目录标签上方建立运行页眉模板，仅在页面上方 10% 且位置、字号、宽度都相符时排除续页的同类页眉；至少八字且等长的页眉允许一个 OCR 替字差异。过滤只作用于目录提取的临时坐标副本，内部同名标题须继续核验，不修改 OCR 侧存，不将此容差用于章节标题命中。保留第四版完整核验缓存，章节核验器仍为 `pdf-heading-2`。
- 低清文字可能损坏「目录」标签；发现阶段最多精读四个具有行列证据的强候选，精细 OCR 确认明确标签后即可停止低清搜索。仅有粗识别或普通数字表格不能因此直接发布。所有最终目标仍逐项核对；重定位仍须唯一的独立内部标题版面，章号与标题分行不妨碍此核对。
- 有界派生缓存同步保存提取器版本、阶段、终态和白名单错误码，不保存原生异常消息；诊断写入独立限时一秒，失败不阻止导入。提示区分识别、保存、任务预算及材料硬上限。用户主动重导入同路径 PDF 时可跳过常规入库，仅重新准备缺失目录，关闭自建解析器及文件句柄；静默监听重扫明确关闭此重试。个人目录及当前已核验目录在解析前即保留；普通开书与临时预览仍不触发目录准备。

## 新增验收材料与限制

### 空缓存恢复与独立目录证据（2026-10-21）

- PDF.js 的文字汇总经公开 `streamTextContent().getReader()` 读取，不要求系统 WKWebView 实现 ReadableStream 异步迭代；失败取消 reader 并释放锁。分段读取校验包含末字节的缓存边界、响应长度与 Content-Range，仅对同一范围重试一次；关闭中止请求，拒绝迟到缓存写入。解析器范围错误及时传给开书及后续文字／版面读取，不悬挂到总任务超时。
- 精细 OCR 首轮最长边 3200px 无字框时最多再以 1200px 精读一次，仍提取字／词框。`vision-multiscale-1` 标记已完成恢复的空白页；旧空缓存可恢复，有文字观察但全部尺度均无字框须失败，不能永久登记为空白。非空及原生文字层原样保留。阅读补字也识别旧空缓存，先显示画面，再经既有队列补字，失败不循环。
- 目录精细证据另存 `vision-contents-1`，1200px 优先、空时再用 3200px；两轮均为精细字框，区别于仅提名页面的 `vision-detect-1`。它不进入阅读缓存页清单、选字或导出，不改既有文字偏移。扫描目录复读后按片段几何覆盖合并，未覆盖的旧片段继续参与全量核验；正文原字层标题不匹配时才按需取独立证据。全部新增精读共用原 96 页／180 秒预算及任务所有权队列。
