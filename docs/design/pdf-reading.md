# PDF 基础阅读

授权范围：2026-10-10 用户要求完善目录层级、全文搜索/复制、注释往返、续读/个人书签、高亮/笔记汇总。2026-10-16 进一步授权收紧预期的本地 OCR 与目录修复；沿用 Glossa 工作区、本机存储及既有个人记录，不增加模型请求或 MCP。

## 导航与定位

- PDF.js 内置 outline 保留父子层级，支持零起始页索引、间接页对象和具名 destination。目录项具有稳定的页 CFI 与递归唯一 ID，供当前位置层级路径及笔记归组使用。
- 保留 PDF page labels（如前言罗马数字与正文阿拉伯数字）。无内置 outline 时，目录显示实际页码作为后备导航，不推测章节。
- 目录位置拆分同步返回页索引，适配现有导航/搜索接口；无效、不存在、越界 destination 不使阅读会话报错退出。
- XYZ / FitH / FitV / FitR 等 destination 使用 PDF viewport 转换并在已渲染文字层定位；没有文字时按页内比例定位。搜索、个人注释和续读使用既有 CFI Range。
- 分页和滚动模式均等待目标文字层就绪后滚到 anchor。内部注释链接及原有后退/前进历史共用这一路径。

## 文本、个人记录与恢复

- 全文搜索沿用逐页本机搜索；文字选择、跨行复制沿用 PDF.js 文字层与既有复制工具。不会把内置注释弹窗的文字混入可见正文摘录。
- 固定版式在导航和滚动结束时报告可见正文 Range。续读保留页内文字位置；个人书签保存可见摘录，固定版式同一物理页的旧页级 CFI 和新页内 CFI 可识别为同一书签，避免重复。
- 阅读位置仍采用延迟保存；关书时取消待执行计时器并立即保存发生变化的最后位置，再刷新书库记录。初次打开的未变位置和临时预览不重写续读位置。
- 高亮和笔记沿用本机 `BookConfig.booknotes`。缩放重建文字层后重新建立 overlay，现有 Annotator 从个人记录恢复高亮/笔记；不复用已经脱离文字层的旧 Range。
- 右侧笔记继续提供高亮/笔记计数、筛选、搜索、目录归组和原文跳转；左侧个人书签保持独立。旧记录不迁移、不清理，不向 PDF 原文件写入个人记录。

## 验收与边界

原创四页 PDF 夹具包含嵌套目录、混合页码、每页可搜索文字、跨行文字、双向内部注释链接和内置注释。真实 Chromium 使用 PDF.js 解析和渲染，验证目录跳转、层级路径、全文命中、页内定位、选文复制内容、个人记录筛选/归组、注释往返、书签匹配、缩放后的高亮和重开定位。确定性回归另覆盖无目录与坏链接、快速关书和临时预览不保存。

同页多个目录项的笔记归组按页级 CFI，不声称已恢复精确的同页章节边界。Chromium 验证不替代 macOS 原生 WebView 实机验收。

## 本地识别文字（2026-10-16）

- 首版仅 macOS 12 及以上的 Tauri 桌面端。构建时用系统 Swift 编译随包的 PDFKit／Vision 处理器，运行时直接启动经过字节校验的该处理器；不调用 shell、MCP、网络或外部模型，不要求用户安装 Python 或 OCR 工具。
- 主动点击左侧「识别文字」才启动。PDFKit 按旋转后的 crop box 渲染不超过 3200px 的页面，Vision 返回中英文词／字的归一化坐标与原识别顺序。任何已有文字的页面整体跳过，避免改变旧文字层的 DOM 和 CFI；首版不补识别混合页中的局部图片。
- 原 PDF 不改写。应用本地数据目录 `pdf-local-v1/<完整内容 MD5>/vision-pdf-1/` 保存逐页 JSON 与进度，`outline.json` 独立保存个人目录及版本。前端严格校验坐标、文本长度及页号，只对无原生正文的 `.textLayer` 注入 OCR 字词；搜索与显示使用相同节点顺序，沿用原选择、复制与批注路径。页内搜索采用有界的 16 页读取缓存。
- 单进程串行任务，独立工作进程可取消；每完成一页原子保存，重试跳过已校验的页。切换阅读内容后任务仍可后台进行，重新打开侧栏可查看运行任务；正常退出会终止处理器，已保存页可复用。应用／重开前校验当前文件指纹，源文件变化时拒绝继续复用。
- 当前阅读会话固定已加载的 OCR 页集合，后台任务不自动替换正在使用的文字节点。用户点击「应用识别文字」后保存当前 CFI 与既有配置，再重建阅读器；取消／失败也可主动应用已保存的页。
- 预算：文件最多 2GB／5000 页，单页 JSON 4MB／10000 个字词／100000 字符，单文档缓存约 512MB，开始前全体缓存低于 1GB，单任务 30 分钟。越界停止并保留有效进度，不自动扩展预算或反复重启。

## 修复目录（2026-10-16）

- 侧栏原位展开目录工具，指定实际目录页（单次最多 24 页）及印刷页偏移。只提取具有明确页码的目录行，先匹配 PDF page labels（缺失时使用实际页码），歧义／无法定位的行不生成虚构目标。
- 最多读取 48 个目标页，比较目标页前部文字与目录标题；未核对的候选显示「待核对」，点击标题可跳转检查。OCR 与校验结果只成为草稿，须用户显式「应用」才持久化目录。
- 标题双击／F2／铅笔原位改名，Enter 保存、Escape 取消；页码直接修改，拖动或按钮移动整个分支，缩进／取消缩进保留子树，删除标题时子节点上提。最多 1000 项、6 层，结构与目标页双端校验。草稿保留最近 20 次撤销；当前工作区保留上次应用前的目录用于撤销，随时可恢复 PDF 原目录。
- 目录保存使用修订号比较与原子替换，其他窗口已修改时拒绝覆盖。原始 PDF 书签、个人书签、高亮、批注、书籍哈希与云同步协议保持原样；OCR 和修复目录首版仅本机使用，不嵌入导出文件或扩展同步协议。

## 新增验收材料与限制

原创四页扫描夹具含中英文目录与正文、90° 旋转扫描页及已有文字的页面。由真实本地 Vision 输出词框，Chromium 验证搜索、选择位置、旋转页坐标、缩放后的高亮、重开与旧原生文字定位兼容；Rust 直接运行随包处理器验证取消、续做与原 PDF 字节不变。目录协议与 UI 回归覆盖页码核对、层级移动、原位编辑、取消、重试、保存失败和显式应用。

识别准确率与阅读顺序取决于扫描质量、语言及版式，首版不承诺手写、公式、复杂多栏或竖排精确还原；目录识别依赖明确的标题及页码，未核对项须人工检查。真实用户书籍与 macOS 原生 WebView 尚待开发版实机验收，自动化结果不替代此项。
