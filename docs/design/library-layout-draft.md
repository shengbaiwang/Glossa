# 书库排版草稿（2026-10-18）

## 书库显示菜单（2026-10-18）

首页工具栏使用网格图标加「显示」文字，与导入命令、全局设置齿轮区分。浮层先展示等宽的网格／列表选择，再展示当前视图的封面大小或列表大小；保留自动列数、手动列数及列表百分比，不再让两套尺寸按钮同时出现。封面区集中裁剪／适应和拟物封面，续读作为首页内容开关紧随其后。

主排序、次排序及两套独立方向统一在一个折叠项中，方向使用箭头与升序／降序文字；保留作者／系列的既有自动排序规则。主题与背景直达原全局外观页，避免复制背景资源管理和阅读器配置。拟物封面直接写入原 `librarySkeuomorphicCovers`，从全局主题页移除重复入口，不迁移或覆盖旧偏好。

显示浮层不承载「选择书籍」命令。长按书卡直接进入选择，右键／Shift+F10 菜单及既有选择快捷键继续可用；选择后页头的全选、取消选择、完成与批量工具栏保持原行为。浮层退出返回「显示」按钮焦点；窄屏优先保留操作标签，以 Glossa 标记替代同时占宽的文字品牌。选项按语义使用按下状态、勾选与禁用，图标统一现有墨线体系。

以下作者陈列设计继续有效。源码状态与原生窗口验收边界见 `PROGRESS.md`。

本稿最初响应用户作者页截图。用户于 2026-10-18 授权优化诊断中的交互与排版后，源码采用下文「以封面为主的作者陈列」：保留网格／列表、单本完整封面／多本最多三张叠放、独立缺失作者入口、准确集合标题统计，以及稳定封面展示区和容器自适应列数。作者文字索引保留为设计备选，未实现；正式安装版与验收状态以 `PROGRESS.md` 为准，不追加长期审美偏好规则。

## 问题判断

- `GroupItem` 的网格封面固定使用两行两列，单本作者也只占其中一格，产生大空框和微型封面。它与同屏完整书卡的视觉尺度、信息意义不同。
- `createAuthorGroups` 将没有作者的书保留为普通书卡；`Bookshelf` 又将其与作者聚合混排。因此作者页同时出现作者名／本数和书名／阅读进度，缺少稳定的扫描路径。
- 聚合名称没有书名同等的两行约束，长外文名及夹有译者信息的名称会撑高行。增加网格行间距不能解决这一结构问题。
- 作者页仍显示「全部书籍」子标题与书籍总数，主标题、当前展示实体和统计口径不一致。

## 建议方向

沿用 Glossa 已有的纸墨表面、系统字体、细线和克制的中性色。优先调整展示实体、封面比例、文字宽度和阅读节奏，不依靠新的装饰与常驻操作。

### 推荐：作者索引与书籍网格各司其职

作者、系列首先是查找入口，书籍才是打开阅读的对象。左栏与页头保持原有层级。

**作者索引**

- 一行一个作者入口，名称居前、本数紧随其下，行末显示最多三个小封面。只有一本时显示一张正常比例封面，不预留空拼贴格。
- 宽窗口采用两列目录，内容较少也保持自然的起点与行距；窄窗口收为一列。细分隔线连接行的秩序，不为每行增加外框。
- 名称 14px／1.5、常规至中等字重，至多两行；本数 12px。名称区域优先获得宽度，封面预览可减少到一张；名称原值在详情与键盘／触屏可达的完整名称提示中可读。
- 行高从 104px 起，允许辅助字号及长名称增长，不能用固定高度裁掉文字。预览封面约 38–44px 宽、58–66px 高，保持原比例。
- 页头只保留「作者」及准确的作者数；不再叠加「全部书籍」。多作者的书可在多个作者下出现，作者数不等于总书数。
- 没有作者的书放在独立的「作者未填写」入口中；进入后仍使用普通书卡。不能用陌生的完整书卡混入作者入口。
- 点击作者进入其书籍集合，提供回到作者列表的路径，恢复返回前的滚动和焦点。

**全部书籍与作者内页**

- 无常驻卡片外框和封面底板。封面本身提供色彩和辨识度，轻微封面边缘／阴影只用于区分纸面；交互态沿用现有悬停、选中和键盘焦点。
- 推荐封面宽度约 136–168px，根据实际内容区域计算列数，不只按整个窗口断点决定。沿用现有自动／手动列数与大小设置，不覆盖用户偏好。
- 统一每行的封面展示区高度与顶部基准，图片保留比例；窄封面不拉宽，横版封面不裁字。书名区也从同一基线开始，避免由图片比例决定下一块文字的位置。
- 图片到书名 10–12px；书名 14px／1.45、中等字重，预留两行高度；作者 12px／1.5、一行，缺失时保留行位。作者与阅读进度各自横向对齐，书名到作者 6px、作者到进度 10px，避免不同书名行数带来高低错落。未读不添加「0%」噪声。
- 常规网格列距约 28–36px，行距约 28–36px。先处理每张卡的结构，再确定网格节奏，避免通过增大整行空白掩盖不齐。
- 书名、作者和进度有各自稳定的对齐规则；不再保留仅为聚合卡补齐书籍状态而设置的空白占位。
- 缺失封面使用同等大小、纸墨配色的文字书封。图片加载和失败不能引起封面区与后续行跳动。

**继续阅读**

- 卡片常态与悬停不显示外框，保留键盘焦点与批量选中反馈。
- 状态栏按完整按钮高度布局，不以图标高度限制容器；列表内容不裁切按钮高光和焦点，封面继续局部裁切。触屏信息按钮保持至少 44px 点击区。

### 对照：以封面为主的作者陈列

如果用户更重视凭封面找作者，也可保留作者网格：一本显示完整封面，两三本显示轻微错位的封面叠放，统一展示区，不出现四格空框。下方只显示作者名和本数。该方案视觉上更接近普通书架，但长作者名的阅读效率逊于推荐的作者索引。

## 数据与交互边界

- 本稿不读取或修改真实书库；聊天草稿只使用用户所附截图中的封面作为视觉样本。
- 不根据姓名相似性自动合并作者，不剥离原作者串中的国别、译者或括号信息。只有已有结构化角色字段足够明确时，展示层才可分开角色；元数据编辑继续复用现有入口。
- 分组树、拖动、右键／长按、选择模式、导入、云端状态和保存协议继续沿用已有能力。作者聚合的选择仍作用于实际成员，不能因新排版改变删除或批量操作的含义。
- 不增加额外编辑工作区或常驻教学文字。菜单和触屏入口保持可达，聚合预览的叠放不能遮挡焦点或选择反馈。
- 聊天预览的本数、进度和封面组合均是排版样本，不代表重新读取或校正了用户的元数据。

## 正式接入时的最小顺序与验收

1. 先明确作者页入口与无作者后备，调整页头统计和返回路径；再替换聚合封面布局。
2. 调整普通书卡的展示区、文字基线和自适应列数，保留手动列数／封面 Fit 和 Crop 偏好。
3. 针对 1／2／3／4+ 本聚合、空聚合、缺失／加载失败封面、横竖封面、多语言长名与缺失作者验证；不以像素快照替代导航与批量操作语义测试。
4. 以实际容器宽度 320／768／1024／1440、侧栏收展、手动列数和字号缩放检查布局；分别验证浅深色、RTL、电子墨水、键盘和触屏。
5. 在 macOS 系统 WebView 中目视核对真实窗口、滚动、右键、长按替代入口与返回焦点；浏览器草稿不代表正式应用验收。
