# Markdown 轻量阅读与对话接入

状态：2026-10-25 三阶段源码已实现，单元与浏览器验证通过；日常安装版未更新，原生应用与真实模型验收另记于 `PROGRESS.md`。

## 定位与已有基础

让课程讲义、研究记录和技术资料进入 Glossa 的阅读、批注、提问与回到原文流程。Markdown 阅读属于基础格式支持；对话沿用现有可启停插件。首版范围为桌面本机阅读。

源码已有 `.md` / `.markdown` 识别，`utils/md.ts` 在内存中生成现有阅读器使用的 BookDoc，支持标题目录、表格、代码、脚注及章节定位，无须另建预览器或转换成持久 EPUB。本次将对话扩展到 Markdown，共用现有可重排正文访问；导图继续仅支持 EPUB。源码与自动化证据不代表日常安装版已更新或真实模型已经验收。

## 借鉴 Typora，落到 Glossa

| 参考方向 | Glossa 的具体设计 |
| --- | --- |
| 直接呈现排版后的正文 | 打开即读，默认隐藏 Markdown 标记；沿用纸色、墨色、字体与 Aa 设置，保持清楚的标题层级、段间距和适中的正文宽度。 |
| 连贯的长文阅读 | 新导入 Markdown 默认连续滚动，保留现有翻页选择与已保存偏好；宽表格、代码块独立处理溢出，不撑宽整页。 |
| 清楚的文档大纲 | 左侧继续使用「目录／书签」，目录取自 H1–H6，支持折叠、当前章节指示和点击跳转；正文标题不堆叠永久操作按钮。 |
| 降低阅读干扰 | 使用现有侧栏收起和工具栏机制，把主要面积交给正文。首版不加入自动变暗段落或打字机式强制滚动。 |
| 对复杂内容的可读呈现 | 支持表格、代码、脚注、常用公式、内嵌图片与从明确选择的文件夹中快照导入的相对图片。代码采用克制配色，脚注沿用现有弹窗。 |

正文保持只读；任务列表按原文展示。高亮、批注和摘录从现有选文交互进入，右侧仍为现有笔记与对话，沿用保存失败保留草稿、重试和安全撤销。图表编辑、双链、知识库、源码双栏和 Markdown 写作工具不在本次范围；导图不随对话接入自动扩大格式支持。

## 最小实现路径

1. 阅读与批注：复用原有文件／文件夹／拖拽入口、原文件名默认书名、完整内容指纹和书库分组。保存原始 Markdown 快照；外部修改后重新导入视为不同内容版本，保留旧批注。完成排版、目录、搜索、选文、批注、重开恢复的实际闭环。
2. 对话：通过已有 BookReadingAccess 接口提供 Markdown 的章节读取、关键词检索和来源核验；仅抽取 EPUB 与 Markdown 确实共用的逻辑。更新对话插件的多格式声明与入口判断，不把 Markdown 伪装成 EPUB。沿用「开启引用／关闭引用」；开启时只在发送问题后按需查阅当前文档，关闭时不读取或发送正文，也不复用旧原文材料。完整总结覆盖整个目标，保留取消、预算和失败恢复。
3. 内容适配：在前两步稳定后补常用行内／块公式与本地相对图片。公式保留可核验的源表达式，覆盖代码中的美元符号与货币误识别；图片仅从明确选择的资源根读取并快照保存，原始正文及图片字节共同构成确定性的托管快照，以完整内容指纹核验，相同正文但资源不同单独成档。缺图显示占位与简短原因，不要求用户先转换文件。

单文件首批以正文、内嵌图片为验收范围；相对图片缺失必须明确展示。远程资源不静默联网加载，原文链接由用户主动打开，不作为模型自动检索授权。解析、图片和公式流程沿用内容清理及资源权限边界。

## 已实现的资源与兼容边界

- `.md`／`.markdown` 保持原文件名默认书名，持久导入始终保存独立快照，避免外部改写破坏旧批注；原文件不修改。仅新建配置设置连续滚动，重复导入不覆盖原位置、笔记或个人翻页选择。
- 原始正文无相对资源时保持原字节存储；有本地图片时采用版本化 Glossa Markdown 托管容器，内含原始文件的精确字节和图片字节，继续由 Markdown 适配器读取。它是应用内部存储格式；把托管文件直接交给其他 Markdown 编辑器不属于可移植原文导出。本次未新增导出入口。
- 只有主动导入文件夹／已授权的监视目录提供资源根；单文件导入不自动扫描父文件夹。拒绝根外路径、符号链接与外部协议，仅接收 PNG、JPEG、GIF、WebP、AVIF、BMP。限制单图 8 MiB、总图 32 MiB、64 张；超过限制、缺失或不支持时保留缺图占位。原始正文超过 16 MiB 不尝试资源快照。SVG、远程图片及远程封面不自动加载。
- `$…$`、`$$…$$` 用本机 KaTeX 生成 MathML，不加载外部脚本；公式错误保留原表达式，代码与纯数字货币不误识别。来源读取仅保留一次 TeX 表达式，代码来源保留缩进；来源锚点经当前文档本机核验。
- 所有内容继续清理脚本、事件、外部图片地址和危险公式；图片仅在解析完成并核对快照后绑定。对话面板开启或启用插件不触发模型，关闭引用不读取正文、不复用旧原文依据。原有 EPUB API 保留兼容导出。

## 定位与验收

- 批注及 AI 引用共用可靠的正文定位：保留现有章节／CFI，并以原文摘录及前后文核验；来源绑定文档内容身份，解析缓存另外绑定渲染版本。解析规则更新不得静默使旧批注跳错，无法可靠恢复时保留记录并明确提示。
- 标题、段落、列表、表格、代码和脚注均须验证读到的文本与屏幕正文一致。代码保留语义和缩进；不因语义块分类缺少 code 而漏掉总结材料。来源不足时明确说明，不猜测定位。
- 用原创材料验证短文、无一级标题的长文、中文／重复标题、宽表格、长代码及脚注；公式与资源使用独立原创材料。检验原生鼠标拖选、缩放、窄窗口、滚动／翻页、跳转返回、保存失败、取消和重开。
- 开启引用的问题可定位回真实段落，关闭引用不带正文；打开面板不启动模型请求，停用插件取消活动任务。完整总结必须包括无标题前言、代码和脚注中的相关内容。
- 同文件重复导入保留一条可见记录，同名不同内容分别保存；原文件、个人改名、分组、阅读位置与批注保持完整。
- 单测、浏览器自动化、系统 WebView 和真实模型验收分别记录；实际模型验收使用原创或明确授权材料。本次使用原创材料与模拟模型协议；真实模型和完整原生应用仍需独立验收。
