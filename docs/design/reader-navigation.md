# 阅读位置与目录联动

阅读器共享一份文档级章节索引，每个视图独立管理实际位置、跳转请求、历史和目录滚动。旧 CFI、PDF 物理页、书签、笔记、引用和续读记录仍用原有格式。导航索引不授予正文访问权限。

三项设计分别解决不同问题：Navigator 与 Locator 负责「去哪、实际到了哪」，章节区间负责「此处属于哪一章」，原文与前后文组合锚定负责「是不是同一段文字」。第三项沿用既有引用核验服务，通过后才把目标交给 Navigator。

- `packages/foliate-js/chapter-index.js` 按文档和目录对象缓存索引。目录节点以父路径、原链接和同链接出现次序标识。目录树保持显示顺序，正文位置以资源序号和 CFI 排序；章节起点包含、终点排除。普通位置查询走二分查找，不重新读书。未解析片段、重复落点和未列入目录的非线性资源分别保留降级或无法判定状态。已知 EPUB 附注等独立资源不沿用上一个章节。
- `view.js` 以 Foliate 上报的可见范围为位置依据。显式跳转只有在目标进入视口后才确认；目标保持可见且读者未主动移动时保留目标章节。字号或窗口重排不会直接撤销目标意图。目录侧栏手动滚动、展开或折叠只暂停侧栏滚动跟随，高亮继续更新。
- 每个视图用 `navigation-controller.js` 串行交接渲染任务；较新的绝对请求取代旧绝对请求，连续翻页保持顺序。渲染器在异步获取来源和最终定位前再次检查请求有效性。只有已到达位置进入跳转历史；失效的引用仍由原文核验服务拒绝。
- PDF destination 以物理页和 PDF.js 视口变换定位；印刷页码只展示。只有当前页文字层提供唯一可用文字落点时才细化到页内 CFI。页内精化只排序当前页。旧缓存生成目录如果只有页序号，就保留页级精度；不从标题或邻近文字反推坐标。
- 书内搜索、笔记归组、引用预览和章节路径使用同一位置查询。章节搜索只使用有边界证据的范围。对话／导图的章节选项继续兼容旧 ID、单根隐藏和旧扁平目录的层级投影；提取仍要求原文 DOM 两端可核验。独立旧投影与索引不一致时保留原有受限范围或拒绝提取，不能用粗粒度命中扩展范围。
- EPUB 后台增强继续沿用首屏优先和有界读取，派生导航缓存版本为 5。结构索引由已有目录和定位信息同步建成，精确片段随已加载资源或后台增强补齐。目录和索引随一次发布替换；当前视图无需重建。关闭视图取消其导航请求，最后一个视图关闭后释放共享章节索引，即使书库仍缓存文档对象。

验收分为单元测试、Chromium 和系统 WKWebView。独立 WKWebView 夹具使用非持久数据区，仅打开原创测试 EPUB；不等同于 Glossa Dev 的完整书库流程或实体触控板验收。旧生成 PDF 目录缺少页内坐标时，同页条目仅能按已有页级证据处理。合成大目录的查询与索引对象回收已单独测量，不能外推到真实书库的冷暖开书或进程总内存。详细结果见项目进度。
