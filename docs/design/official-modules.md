# Glossa 官方插件系统与阅读核心

2026-10-21 用户要求借鉴 Obsidian，将对话、导图和 PDF 自动目录插件化，扩展此前两项官方模块。2026-10-22 进一步要求独立插件设置菜单与第三方开发空间。第一版交付随应用提供的可信插件和元数据开发草案，第三方脚本加载、安装、市场与可执行 SDK 暂缓。

## 借鉴与边界

参考 Obsidian 的 [Manifest](https://docs.obsidian.md/Reference/Manifest)、[生命周期](https://docs.obsidian.md/plugins/guides/lifecycle-management) 与 [按需加载建议](https://docs.obsidian.md/plugins/guides/load-time)。Glossa 使用类型化清单、显式触发和可清理的激活范围。清单中的能力是官方实现的依赖说明，并非第三方代码沙箱或动态授权系统；不声称兼容 Obsidian 插件。

核心继续负责阅读、选择、定位、批注／笔记、书库、保存和同步。PDF 已存目录读取、页码导航及阅读中空文字层的本机补字仍属于核心；插件负责主动生成及可选导入时的目录准备。原 PDF、旧 CFI、OCR、个人目录及笔记不迁移、不清除。

## 清单与触发

`glossa/plugins/manifest.ts` 定义可运行时校验的 v1 元数据草案，包含稳定 ID、名称、作者、语义版本、API 版本、触发点、格式与依赖能力。`registry.ts` 用同一协议声明三项内置插件，不读取用户数据。解析外部清单不会注册插件、调用模型或执行代码；未知字段、能力及不兼容 API 版本拒绝。命名空间示例与开发约定见 [插件开发草案](../development/plugins.md)。`loaders.ts` 为三项插件提供固定动态导入白名单，不接受设置中的路径、URL 或脚本。`glossa/modules/registry.ts` 保留现有集成兼容接口。

| 插件 | 激活条件 | 停用效果 |
| --- | --- | --- |
| 对话 | 启用、EPUB、打开现有对话面板 | 卸载面板、取消请求、隐藏节点提问入口；保留插件内部设置 |
| 导图 | 启用、EPUB、打开现有导图面板 | 卸载面板、取消生成、保留图与检查点 |
| PDF 自动目录 | 启用、打开 PDF 右侧「目录生成」后主动生成，或开启导入自动生成后持久导入／重导入；支持本机识别 | 卸载面板、停止目录任务，后续导入跳过目录生成 |

阅读标签从面板插件列表按当前格式筛选，PDF 右侧提供「目录生成／笔记」，EPUB 继续提供启用的对话／导图及笔记。书籍菜单可打开同一目录插件面板。对话和导图全停用仍保留笔记；共享模型服务由这两个插件的内部设置进入，停用仍可预先配置。

### PDF 主动调用

参考 Obsidian [侧栏入口与命令](https://obsidian.md/help/sidebar)，将启用、打开和执行分开。打开目录面板只读取原生目录状态与恢复快照；点击后才动态加载目录任务，以自有解析器运行，关闭或停用不销毁阅读文档。原位显示阶段、取消与失败重试；不增加目录页输入、偏移校准、草稿应用或集中编辑表单。已有个人目录包括主动清空继续保留。

成功后通过核心目录服务更新左侧导航，并刷新活动阅读器的 TOCProgress；不重建 renderer，不改变 CFI、历史或选文。显式重生成绕过旧自动目录的短路保留，继续逐项核验；失败不清空上次自动目录。重生成前在本机有界 IndexedDB 保存一步恢复快照（最多 16 项、每项 600KB、总计 2MB），绑定原生文件指纹、页数及预期保存修订号。生成失败不会使上一修订的恢复失效；恢复使用当前修订号原子保存，不覆盖并发编辑或个人目录。快照为有界恢复缓存，不是长期版本备份。

「设置 → 插件 → PDF 自动目录」内的「导入时自动生成目录」独立保存为 `pdfContentsOnImport`，缺省为 true 兼容现有配置；关闭后仍可从右侧主动生成。只在显式修改后同步该布尔偏好，普通旧窗口广播不能复活它。启用本身不启动任务。

## 生命周期与错误隔离

面板宿主复用 React 挂载／卸载生命周期，通过统一白名单按需加载。局部加载／渲染错误提供原位重试，现有功能 effects 负责请求、观察器、监听与计时器清理，核心持久化服务保留未落盘内容。

非面板任务使用 `runPluginTask`：每次显式激活创建独立 AbortController 和设置订阅，停用立即取消，即使马上重新启用也不能复活旧 signal。结束或失败后释放订阅；下一次显式操作才能新建激活。PDF 入口拆至 `glossa/plugins/pdfAutoContents.ts`，在路径、缓存、文件、解析和动态加载各异步边界检查取消，向现有目录算法传递同一信号，并在 finally 释放插件自有解析器和文件句柄；导入方提供的解析器仍由导入方负责。算法的全覆盖核验、串行队列、原生取消和保存冲突保护保持。

加载失败不会使书籍导入失败；目录准备失败使用原有分类提示，取消不伪报核验失败。已经开始的原子保存及终态诊断可以完成，不通过清空历史释放资源。运行时可能保留已加载代码缓存。

## 设置与数据保护

「设置 → 插件」为独立一级菜单，使用既有设置导航、键盘操作和窄屏分类选择器，记住上次打开的分类。页面分为「内置插件」与「第三方插件」，后者明确尚未开放安装，不呈现不可用的安装操作。内置插件以响应式网格呈现，卡片保留图标、名称、启停状态及开关，右上角三点进入同页内部设置。对话内含提示词与模型服务，导图沿用同一模型服务，PDF 内含导入自动生成偏好；不创建第二套模型配置或独立弹窗，返回恢复原卡片按钮焦点。停用仍可修改设置，打开设置不启动生成／模型请求，只有进入相关设置时才加载提示词或模型配置界面。切换内部设置时保留插件开关和 PDF 偏好的保存状态，避免重复提交及丢失失败反馈。

设置搜索可打开内部偏好；旧 Models／Conversation 快捷入口和历史分类转到插件内部，旧 `settings.general.module.*` 搜索目标转到新位置 `settings.plugins.*`。旧 `officialModules` 字段继续使用，包含 `pdfAutoContents`；缺省全部启用，无迁移。保存失败只恢复本次标记，保留同期其他偏好，提示可重试。显式保存成功后只广播此次布尔补丁；接收端只接受清单中的已知 ID 和布尔值。普通设置广播不携带插件标记，防止旧窗口重新启用刚停用的插件。

停用不删除历史、来源锚点、生成依据、个人编辑、检查点、目录或 OCR。启用不自动打开面板、请求模型、生成目录或继续检查点。引用关闭不读取正文；引用开启仍按需取材，来源核验、白名单、预算和钥匙串不变。PDF 插件不接入模型或云 OCR。

验证旧配置、独立开关、全部关闭、标签回退、失败保存、跨窗口补丁、按需加载、停用取消、迟到加载、异常隔离、重启用与历史保留。使用原创 EPUB/PDF 和隔离存储测试；模拟模型与原生边界不代表真实模型或完整 Tauri 应用验收。实际结果只记录于 `PROGRESS.md`。
